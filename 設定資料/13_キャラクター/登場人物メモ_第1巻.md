## 主人公の誕生前〜転生の仕組み

### 転生と記憶の扱い

| 時期 | 状態 |
|------|------|
| 前世の死〜今世の誕生 | この間の記憶は失われている。夢の中の記憶のような断片として残る程度 |
| 胎内〜誕生後 | 無意識で念話・魔法を使ってしまうことがある |
| 誕生後 | 前世の記憶を持ったまま意識がある。0歳から猛烈に知識を吸収する |

### 5系統遺伝情報の継承と母との同調

- 女性の[[副魔石]]は出産時、5系統（地中・水棲・火山・空中・群体）の遺伝情報を子の主魔石の「種」に転写する（[[属性の遺伝起源]]。全員に起こる正常な継承）
- 主人公の場合、母セレストリアが稀有な「5系統均衡発現」の主魔石構造（＝同調魔法使い）を持っていた結果、母の副魔石にも5系統が均衡濃縮されており、その情報が主人公の主魔石の種へ転写された。これにより主人公は母と同じ「5系統均衡発現の主魔石構造」を受け継ぎ、同調魔法使いとして生まれた（同調能力は主魔石構造由来であって副魔石由来ではない）
- 通常はその転写現象自体を誰も自覚しないが、今回は主人公が**転生者として胎内で既に意識を持っていた**ため、母の同調魔法を胎児側から仲介する異常事態が起き、母は胎児と「会話」できるほど強く同調魔法を使うことができた

## 母と主人公の「誕生前の繋がり」

### 時系列

| 母の年齢 | 出来事 |
|---------|--------|
| 10歳頃 | 誰かに話しかけられるような感覚が始まる。気のせいだと思っている |
| 14〜15歳頃 | 声がより明確になり始める。少しずつ会話できるようになる |
| 16歳・スタンピード直前 | はっきりした会話が成立。防衛作戦を「声の主」から提案される |
| スタンピード中 | 竜との対話・連携などを「声の主」のアドバイスを活かして実行 |
| スタンピード後〜王妃就任 | 声との交流は続くが、しだいに静かになっていく |
| 主人公誕生 | 声が赤子の泣き声と重なり、「あの声だ」と確信する |

### 主人公側の状態（この時期）

- 前世と今世の間の時期の記憶は曖昧で、夢のように断片的
- 母に話しかけていた自覚は薄い
- スタンピードの戦略提案なども、どちらかといえば無意識・半覚醒の状態で行っていた

## 誕生時のエピソード

### 聖女発覚の瞬間

- 出産は難産だったか、あるいは産後に母が傷を負った
- 主人公が無意識のうちに同調魔法を使い、母の傷を回復させてしまう
- これを立ち会っていた者が目撃し、「この子は聖女だ」と広まる

### 念話の再会

- 誕生直後、主人公が無意識に念話で母に話しかける
- 母は以前の「声」との経験からすぐに気づく
- 「やっぱりあなただったのね」という確信
- 他の者に悟られないよう、以後は念話だけで会話するようになる

### 0歳からの成長

- 母との念話を通じて外の情報・言語・世界観を急速に吸収
- 表面上は普通の赤子を装う
- この「普通に見せる」判断ができること自体が、前世の経験によるもの

## 第1巻の軸：0〜1歳の暗殺未遂

### 概要

主人公が聖女だと発覚したことで、王室内の特定勢力が排除に動く。
母と主人公が協力して暗殺を切り抜けるエピソードが第1巻の核となる。

### 実行犯

- 王室に属する王子のひとり
- 聖女の血を持ち、黒幕に従う立場
- 詳細未設定

### 黒幕：先王（仮称）

**立場・背景**

- 王室で最も権威のある男性。現在50歳前後
- かつて「王」として長年にわたり王妃たちの相手を務めてきた
- 現在は「先王」として王室に留まり、実質的な国内権力を握っている

**なぜ権力を持つか**

王妃会議が名目上の最高権力だが、王妃たちは国家最高戦力であるため、子を産むと戦場に戻る。
日常的な国内統治・政務の多くが空白になりがちで、王室の先王がその空白を長年にわたって埋めてきた。
結果として、表の権力（王妃会議）とは別に、裏の実権（先王）という二重構造が生まれている。

**主人公への脅威感**

- 聖女の血を女性が持つ＝王室が不要になる可能性
- 自分の血脈（息子たち）の価値と地位が根底から揺らぐ
- 数十年かけて築いた裏権力が瓦解するリスク
- 感情的な脅威というより、冷静な権力計算からの排除判断

**先王の称号について（要確認）**

「先王」＝かつて王室で「王」として機能し、現在は退いた男性に与えられる称号（案）。
王室には常に現役の「王」が一人おり、世代交代すると前の王が「先王」として王室内に留まる。
今回の黒幕はこの「先王」の立場にある。→ 名称は要相談

## この構図が機能する理由

| 矛盾点 | 解消方法 |
|--------|---------|
| 強い子を殺す動機 | 先王の動機は「戦力の損失」より「権力構造の維持」が優先。冷静な計算 |
| 王妃会議が気づかないか | 王妃たちは戦場にいることが多く、王都の内政に目が届きにくい |
| 0歳児が生き延びられるか | 母親が同調魔法の使い手＋念話で主人公と連携できるという特殊な状況 |
