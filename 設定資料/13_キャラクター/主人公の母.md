# 主人公の母：設定

## 基本情報

- **名前**：セレストリア
- **出身**：[[東の国]]・南の辺境伯家の令嬢
- **立場**：功績により王妃に迎えられた（武闘大会ではなく功績枠）
- **髪色**：**碧（あおみどり）**（[[風|風属性]]の証。鮮やかな碧色は高い魔力を示す）
- **魔法適性**：[[風|風魔法]]（主系統）＋[[同調魔法]]（主魔石の特殊構造：古代群体系統遺伝子の均等発現）
- **戦闘力**：個人でB級程度（→ [[魔物ランク表]]）

---

## 能力の詳細

### 風魔法
正規の魔法適性。B級相当の実力を持つ。攻撃・移動補助・索敵に使える汎用性の高い系統。

### 魔物とのコミュニケーション（同調魔法の応用）
彼女の[[同調魔法]]は、主魔石が古代5系統（地中・水棲・火山・空中・群体）の遺伝子を均等に発現するという極めて稀な構造に由来する（[[属性の遺伝起源]]）。
この均等発現により、マーキング済みの自分用魔力を相手の魔力分子に精密に「重ね合わせる」ことができ、人間だけでなく魔物にも向けられるという極めて稀な使い方を成立させている。
生物の魔力に同調して意思や感情を感じ取り、簡単な意思疎通ができる。魔物を「制御」するのではなく、あくまで「対話」に近い能力。

**主人公出産後の変化：**
女性の[[副魔石]]は古代5系統の遺伝子を濃縮した生殖器官であり、出産時にその濃縮情報は子の主魔石の「種」に転写される。セレストリアの場合、稀有なほど均等にそろっていた5系統遺伝子の濃縮バランスがそのまま[[主人公]]に引き継がれ、出産後に再生成された彼女自身の副魔石では元の完全な均等配列を再現できなかった。
結果として、主魔石を経由する自分の同調魔法の精度が恒久的に低下する。風魔法は主魔石単独の回路として問題なく使えるが、魔物との繊細な対話は以前の精度では行えなくなった。
→ [[主人公]]が聖女の血（[[同調魔法]]）を持つ根拠のひとつ。

## 生い立ちとスタンピード防衛（番外編の軸）

### 時系列

| 時期 | 出来事 |
|------|--------|
| 〜15歳 | 王都の貴族学院に在籍 |
| 16歳 | 貴族学院卒業、南の辺境伯家に帰郷 |
| 帰郷直後 | 南からのスタンピード発生 |
| スタンピード中 | 防衛戦に参加、竜たちと協力しS級魔物を討伐 |
| スタンピード後 | 竜の生き残りと共に領地防衛を続ける |
| 後日 | 功績を認められ王妃として迎えられる |

### スタンピードの概要

- 発生源：南からのS級魔物（詳細未設定）
- 仕組み：S級魔物に追われた大量の魔物が北へ流れ込むスタンピード
- 帰郷したばかりの彼女が防衛戦に巻き込まれる

### 防衛戦の経緯

1. 辺境領の騎士・兵士だけでは歯が立たない状況に陥る
2. 逃げてきた魔物の中に竜種がいることに気づく
3. 同調魔法を使い、竜たちが「S級魔物から逃げている」ことを感じ取る
4. 竜たちと対話し、「共通の敵を倒す」という合意を取り付けることに成功
5. 人間部隊＋竜連合でS級魔物を討伐
6. 竜の多くは戦闘中に死亡。数匹が生き残る

### スタンピード後

- 生き残った竜たちと引き続き共に暮らす関係になった
- 南の辺境領の防衛戦力として竜たちが定着
- この異例の事態が王都に伝わり、功績として認められ王妃の座へ

## 王妃としての立場

- 武闘大会優勝ではなく「功績枠」での王妃就任
- 南の辺境出身という生まれから、王都の貴族社会では外様的な立場もある
- 実家（辺境伯家）には竜が残っており、今もそこを守っている
