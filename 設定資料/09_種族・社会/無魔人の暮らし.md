# 無魔人の暮らし

全人口の92〜95%を占める無魔人は、魔石を持たないが微量の魔力を保持している。「魔法が使えない無力者」ではなく「魔法が弱い多数派」であり、外敵の脅威が人類の協力を強制する世界では、無魔人も社会の不可欠な構成員である。格差は確実に存在するが、その本質は「出力差」というより「効率差」と「時間差」である。

---

## 無魔人とは何か

- 魔石を持たない人間。全人口の92〜95%
- **微量の魔力は持っている** → ごく限られた補助操作は可能（[[魔力分子とマーキング]]「無魔人とマーキング」参照）
  - 主魔石を持たず古代5系統の属性遺伝子も発現していない（[[属性の遺伝起源]]）ため、**直接的な属性魔法（炎を起こす・水を生み出す等）は事実上不可**
  - できるのは、体組織全体に弱く広がったマーキング能力で、**魔石持ちが起こした現象を延命・増幅**する補助操作（すでに燃えている火に魔力分子を薄く供給して火持ちを少し良くする、水魔法使いが動かしている水流の近傍で流れをわずかに整える、自分の腕力を体表マーキングで数%底上げする、等）
  - 基礎教育で微量マーキングの使い方を訓練する
- 魔石がないため魔力の集中・増幅ができず、単独で完結する属性魔法は起こせない → 魔石持ちとの圧倒的な出力・質の差
- **「魔法が使えない」のではなく「魔法の発源にはなれず、魔法使いの補助しかできない」**

## 無魔人の1日（農村の成人女性の場合）

```
【日の出・朝の鐘】
・起床。かまどの残り火に薪を足す。**火守（火魔石持ち）がかつて充電した着火用術式石**を弱く駆動して（数人がかりで触れる必要がないほど弱い刻印の安価な術式石）火を起こす
・井戸まで行き、縄と桶で水汲み。3〜5往復（重労働）
  → 水魔法使いが村にいれば共同水場に水が供給されている
・朝食の準備。かまどで粥を煮る。火加減は自分のマーキング済み微量魔力で残り火の延命を少し手伝える程度

【午前の鐘】
・畑仕事（鍬で耕す。種まき。草取り。土魔法は直接使えないため、土守（土魔石持ち）が事前に起こしてくれた耕運の仕上げを体表マーキングで少し整える程度）
・または洗濯（泡実の石鹸を使って洗う。川か共同洗い場で）
・子供がいれば世話も並行。ただし学齢の子は区学舎・村学舎に通っている

【昼の鐘】
・昼食（パン・粥・乾燥野菜・煮込みなど。食文化は意外と豊か）
・この世界は食材・調味料が充実している → 無魔人の食事も「まずい」わけではない

【午後の鐘】
・続きの畑仕事、または薪集め
・冬が近ければ薪の備蓄作業
・衣類の繕い（手縫い）
・定期市の日は買い物や情報交換の時間

【夕方の鐘】
・夕食の準備。鍋で煮込み料理
・家族で夕食。獣脂ランプか安価な術式石の灯り
・暗くなったら就寝。術式石が買える家庭は夜もしばらく活動可能
```

**→ 一日の大部分が肉体労働だが、「惨め」とまでは言えない。**
微量魔法での補助、泡実の石鹸、充実した食材、基礎教育を受けた識字力など、
現実の中世農民よりは恵まれている部分もある。
**ただし魔石持ちとの効率差は歴然。**

## 魔石持ちとの生活格差

| 生活要素 | 魔石持ち | 無魔人 |
|---------|---------|--------|
| 水汲み | 水魔法で1分 | 井戸から手汲み（共同水場があれば軽減） |
| 火起こし | 術式石で一瞬 | 微量魔法で補助しつつ火打ち石 |
| 調理 | 術式石で温度制御 | 薪の火力＋微量魔法で多少の調整 |
| 洗濯 | 水魔法で30分 | 泡実の石鹸で手洗い。半日仕事 |
| 照明 | 術式石で明るい夜 | 獣脂ランプ or 安価な術式石（買えれば） |
| 暖房 | 術式石で快適 | 薪の暖炉。薪の確保が重労働 |
| 入浴 | 水魔法で頻繁に清潔に | 公衆浴場 or 川。頻度は少ないが不潔ではない |
| 家の修理 | 土魔法で即日 | 土魔法使いに依頼（有償）。簡単な補修は自力 |
| 移動 | 強化魔法で速い。走鳥騎乗 | 徒歩 or 家畜馬（持っていれば） |
| 医療 | ポーション＋自己回復魔法 | ポーション＋薬草（自己回復魔法は微量すぎて効果薄い） |
| 夜の活動 | 長い（術式石の明かり） | 短い（灯りが限られる） |
| 耕作 | 土・水・有機魔法で高効率 | 人力＋微量魔法。3〜5倍の時間がかかる |

**→ 格差は確実にあるが、「絶望的な差」ではない。**
術式石が安価に流通している都市では、無魔人も照明・暖房を得られる。
格差が大きいのは「効率」と「時間」。同じ結果を得るのに何倍もの時間がかかる。

## 無魔人の社会的立場

### 「不可欠な多数派」

- 全人口の92〜95%が無魔人 → **社会の基盤そのもの**
- 農業の大部分を無魔人が担っている（魔石持ちは5〜8%しかいない）
- 荷竜の世話、そりの荷役、建築の補助作業、家事全般
- **無魔人がいなければ社会は回らない** → これは支配層も理解している
- 外敵の脅威が「内部の差別を激化させる余裕がない」状況を作っている

### 協力が前提の社会

- スタンピード時には無魔人も総動員される（後方支援・避難誘導・物資運搬）
- 都市の大型魔道具（浄化・照明・感知）の維持には魔力の集約が必要 → 無魔人も微量魔力を供出する場合がある
- 税は魔石持ちが魔力、無魔人が労役か貨幣 → **全員が何らかの形で貢献**
- → 「無魔人は不要」という極端な差別は社会構造として成り立ちにくい

### 国ごとの扱いの違い

| 国 | 無魔人の扱い |
|----|------------|
| ルクスマーレ王国 | 最も平等に近い。商人として成功した無魔人も多い。海運の荷役で重宝 |
| ドミナトゥス帝国 | 制度上の差別が最も大きい。魔石持ち貴族の権威が強い。ただし農業の主力として不可欠 |
| コンコルディア盟邦 | 戦闘力が評価基準。無魔人でも後方支援で功績を挙げれば認められる |

## 無魔人の教育と職業

### 基礎教育（6〜10歳・義務）

- 魔石持ちと一緒に区学舎・村学舎で学ぶ
- 読み書き・算術・魔物知識・基礎魔法操作・身体訓練
- **微量魔法の訓練が重要** → 上手く使えるかどうかで生活の質が変わる
- この時期は魔石持ちの子供と普通に交流する

### 専門教育（10歳〜）

| 進路 | 内容 | 備考 |
|------|------|------|
| 農業・牧畜 | 親元で実地 | 最も一般的 |
| 商人見習い | 商家・ギルドに弟子入り | 読み書き・算術が武器 |
| 職人補助 | 魔法職人の補助作業 | 大工補助・素材加工・型枠作り |
| 薬草師 | 薬草の採集・調合 | 魔法不要の重要職。ポーションの原材料を支える |
| 荷竜・走鳥の飼育係 | 家畜の世話・調教補助 | 大型家畜の管理は専門技能 |
| 兵站・後方支援 | 軍の後方支援訓練 | 補給・荷運び・野営設営 |
| 料理人 | 術式石を使った調理 | 食文化が発達した世界では需要が高い |

### 無魔人でも成功できる道

- **商人**：交渉力・会計力・情報力は魔法と無関係。裕福な無魔人商人は珍しくない
- **薬草師**：ポーション経済の原材料を支える。知識と経験が勝負
- **料理人**：食文化が発達しているため、腕のいい料理人は魔石持ちにも重宝される
- **荷竜の御者**：大型家畜の扱いは専門技能。商人ギルドの荷竜隊で安定収入
- **語り部・楽師**：才能があれば魔法は関係ない

## 無魔人の生存戦略

### 術式石の恩恵

- **術式石は無魔人でも使える**（魔力を込める必要がない、起動済みのもの）
- 照明・暖房・冷却の術式石を購入できれば生活の質が大きく上がる
- 都市の無魔人は術式石の恩恵を比較的受けやすい
- 農村の無魔人は術式石が高価で手が届きにくい → 都市との格差

### 共同体の互助

- 無魔人が多い地区では**互助の仕組み**が発達
  - 水汲みの当番制
  - 薪の共同備蓄
  - 共同育児（学齢前の子供を預け合う）
  - 定期市での情報共有
- この互助ネットワークが無魔人の生活を支えている

### 魔石持ちとの関係

- 敵対ではなく**相互依存**が基本
- 魔石持ちは少数 → 農業・荷役・家事など無魔人の労働力なしには生活できない
- 無魔人は魔石持ちの魔法サービスがないと効率が著しく落ちる
- → **支配・被支配の関係にも見えるが、本質は分業と協力**
- 外敵の脅威がこの関係を強化している（争っている余裕がない）

## 無魔人の不満と社会的課題

### 格差は「時間」に現れる

- 同じ仕事をするのに無魔人は3〜5倍の時間がかかる
- 余暇が少ない → 自己研鑽の時間がない → 格差が再生産される
- 基礎教育の義務化はこの悪循環を多少緩和しているが、根本的な解決にはならない

### 術式石へのアクセス格差

- 高品質な術式石は貴族・軍が優先確保 → 庶民には中〜低品質が回る
- さらにその中でも魔石持ちが優先される傾向 → 無魔人は最後
- 都市と農村の格差も大きい

### 「隠れ持ち」の問題

- 魔力検査を受けずに無魔人として育った魔石持ちが稀にいる
- 無魔人コミュニティの中で密かに魔法を使う者
- 発覚すれば「詐称」として罰せられる国もある
- 逆に、魔石持ちの義務（魔力供出・兵役の前衛配置）から逃れるために隠す者もいる
