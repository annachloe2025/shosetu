# 念写魔法（ねんしゃまほう）

## 概要

「術者が見ているものを、魔紙に映し出す」魔法。
現代でいうカメラのシャッターを切る動作に相当する。

世間的には**感知系魔法の応用**として分類・認識されているが、
本質的には**同調魔法の一種**である。

---

## 魔紙（まし）

念写を受け取るための専用の紙。通常の紙とは異なり、有機魔法（木工系）で特殊な加工が施されている。

### 魔紙の作り方（有機魔法との連携）

```
① 有機魔法（木工系）で繊維を均一に整え、薄い紙を作る
② 完成した紙に対し、魔力を極めて薄く・均一に張り込む
　（紙全体に魔力の膜をコーティングするイメージ）
③ 魔力が定着したものが「魔紙」となる
```

- 魔力の薄さ・均一さが品質の鍵。厚みが偏ると転写ムラが生じる
- 一般的な魔力操作の細かさが求められる為、熟練の有機魔法（木工系）使いが作成する
- 魔力を失うと通常の紙と同じになる（転写済みの像は維持されない）

### 魔紙の反応メカニズム

念写が行われると、魔紙は以下のように反応する。

```
1. 念写魔法が魔紙に触れる
　　↓
2. 魔紙全体が一瞬発光する（魔力が刺激を受けた反応）
　　↓
3. 術者のイメージを受け取った部分：魔力が消費・消滅 → 黒くなる
4. イメージを受け取らなかった部分：魔力がそのまま残る → 白のまま
　　↓
5. 結果：白黒の像が魔紙に焼き付く
```

**なぜ黒くなるか：**
魔力が宿っている部分は白（発光）。
術者のイメージを受け取った部分はその魔力を消費してしまい、白ではなくなる。
つまり「魔力が抜けた＝黒」という原理である。

### 特性

| 項目 | 内容 |
|------|------|
| 解像度 | 術者の魔力細工の精度に依存。熟練ほど細かい |
| 色彩 | 白黒のみ（魔力の有無しか表現できない） |
| 保存性 | 転写後は魔力不要。通常の紙として保管できる |
| 再利用 | 基本的に一度使い切り（魔紙の魔力を消費するため） |
| サイズ | 魔紙のサイズが転写範囲の上限 |

## 念写の仕組み

### 感知系魔法との関係

感知系魔法は、術者が自分の魔力を周囲に広げて情報を「読み取る」魔法である。
念写魔法はこの延長線上にある。

```
感知系魔法：自分の魔力を広げ → 環境の情報を「受け取る」（一方向・内側へ）
　　↓ 拡張
念写魔法：自分のイメージを魔力に乗せ → 外の対象（魔紙）へ「伝える」（一方向・外側へ）
```

感知魔法が「外から情報を引き込む」のに対し、
念写魔法は「内側の情報（見たもの・イメージ）を外へ送り出す」動作である。
方向が逆になっているだけで、魔力を媒体とする点は同じ。

### 生物との違い

| 対象 | 念写のしやすさ | 理由 |
|------|-------------|------|
| 魔紙 | 容易 | 生物ではないため魔力をはじかない |
| 生物（他人） | 困難・はじかれる | 生物は固有の魔力を持ち、外部の魔力を自然に弾く |

**生物への念写ははじかれる**のが原則。
これは感知系魔法でも同様で、感知は「接触せずに情報を読む」から機能するが、
魔力を「相手の内側へ送り込む」行為は弾かれる。

## 普通の魔導士と同調魔法士の違い

### 普通の魔導士

```
術者 ──（念写の魔力）──→ 魔紙　✅ 転写成功
術者 ──（念写の魔力）──→ 他人　❌ はじかれる
```

- 魔紙には問題なく念写できる
- 他人の脳・視覚にイメージを送ることは不可能（はじかれる）
- 「自分が見たものを記録する」用途に限定される

### 同調魔法士（主人公）

```
術者 ──（同調）──→ 他人の魔力と接続
　　　　　　　　　↓
　　　　　　　イメージを他人の内側へ送る　✅ 転写成功
```

- 同調魔法で相手の魔力と繋がっているため、「はじかれる」壁を越えられる
- 他人の脳・視覚に直接イメージを届けることができる
- 「相手に見せたいものを見せる」が可能になる

### 比較表

| 能力 | 普通の魔導士 | 同調魔法士 |
|------|------------|-----------|
| 自分のイメージを魔紙に転写 | ✅ できる | ✅ できる |
| 自分の見たものを魔紙に記録 | ✅ できる | ✅ できる |
| 他人にイメージを「見せる」 | ❌ はじかれる | ✅ 同調中は可能 |
| 他人から見たものを記録する | ❌ 不可 | ✅ 同調中は可能（相手が許可した場合）|

## 本質：同調魔法の一種である理由

念写魔法の本来の姿は「自分のイメージを相手に伝える」同調魔法の延長である。

```
同調魔法の基本：術者 ⇄ 相手（双方向の魔力接続）
　　↓ 片側だけ切り取ると
念写魔法の本質：術者 → 相手（一方向：イメージを送る）
```

ただし「相手が魔紙（無生物）」の場合は、同調魔法の術式を使わなくても成立してしまう。
生物は魔力を弾くが、魔紙は弾かないからである。

この「無生物ならはじかれない」という例外的な事実により、
同調魔法の資質がない一般の術者でも念写が使えるようになった。

**結果として世界では「感知系魔法の一種」と誤認されている。**
感知系の熟練使いが「延長で使えるようになった」と考えられており、
同調魔法との繋がりに気づいている者は現時点でほとんどいない。

## 実用用途

### 記録・文書

- 書面の写し取り（大量の書類を素早く複製）
- 事件・現場の記録（証拠として機能）
- 肖像・風景の記録（絵師の代わりとして機能）

### 通信・伝達

- 地図や図面を遠方の者に正確に伝える（念写した紙を送付）
- 複雑な術式を誤りなく写し取る（術式の正確な伝達）

### 同調魔法士限定の用途

- 離れた者に映像で状況を伝える（念話より情報量が多い）
- 夢や記憶のイメージを相手に見せる（証言・説明に活用）

## 習得難易度

| 術者の種類 | 難易度 | 補足 |
|-----------|--------|------|
| 感知系適性あり | 中程度 | 感知系の延長として習得しやすい |
| 感知系適性なし | 高い | 魔力の「送り出し」の感覚が掴みにくい |
| 同調魔法士 | 比較的容易 | 本質的に同調魔法と同系統のため |

精度を上げるには「自分の視覚情報を魔力パターンに変換する」訓練が必要。
最初は輪郭がぼやけた粗い転写しかできず、練習とともに鮮明になっていく。

## 主人公魔法との関連

念写魔法は主人公の魔法コンピュータ構想の**STEP 1・最初の部品**に位置づけられる。

```
念写魔法（カメラ）
　→ 魔石記憶（ストレージ）
　→ 遠隔視覚魔法（監視カメラ）
　→ 魔石ネットワーク（インターネット）
　→ 魔法プログラミング（ソフトウェア）
　→ 魔石サーバー（クラウド）
```

主人公が念写を同調魔法と意識的に組み合わせ、
「魔石に情報を保存する」という発想に至ることで STEP 2 へ進む。

詳細は「主人公魔法.md」を参照。
