# 記録魔法・魔石記憶（きろくまほう・まぎしきおく）

## 概要

「念写魔石に同調することで、過去に転写した映像を自由に閲覧する」技術。
主人公の魔法コンピュータ構想における**部品②：ストレージ・アルバム相当**。

独立した魔法というより、「**念写石 ＋ 同調**」の組み合わせによって自然に生まれた能力である。
この性質に気づいているのは、現時点で主人公のみ。

**同調魔法士にしか使えない。**

---

## 前提：魔石の刻印と念写石

魔石には同じ魔法を繰り返し行うことで、その魔法が「刻印」される仕組みがある。
刻印された魔石は、術者が少量の魔力を流すだけでその魔法を自動で発動する。

念写魔法を繰り返し使った魔石（以下「念写石」）は、
術者が念写を行う際の中継点として機能するようになる。

---

## 核心の発見：念写石は映像を蓄積している

### 気づきのきっかけ

念写石を使って念写を行うと、その映像が魔紙に焼き付く。
しかし主人公はある疑問を抱く。

> 「映像は魔紙に写った。でも、魔石の中にも映像が残っているのでは？」

念写は「術者のイメージを魔石が受け取り、魔紙に送る」という流れで行われる。
ならば魔石がイメージを「中継」した瞬間、その残像が魔石内部に痕跡として留まるはずだ。

### 実験①：直前の1枚を取り出せるか

```
念写石を使って念写を1枚行う
　↓
魔紙への転写が完了した後、念写石に触れたまま目を閉じる
　↓
念写石に同調を試みる（「さっき通過した映像をもう一度見せてくれ」と意識する）
　↓
【結果：成功】
　→ 念写石の内部から、直前に転写した映像が自分の脳に流れてくる
```

**→ 念写石は使用のたびに映像を蓄積していた。**

### 実験②：複数枚を順番に取り出せるか

```
念写石を使って異なる映像を5枚連続で念写する
（1枚目：部屋の全景、2枚目：窓の外、3枚目：手元の本、…）
　↓
念写石に同調し、「1枚目の映像」を意識して引き出す
　↓
【結果：成功】
　→ 5枚全てが魔石に積み重なっており、意識して選ぶことで任意の1枚を取り出せる
```

**→ 念写石は複数の映像を区別して保持しており、同調によって選択・閲覧が可能。**

---

## 記録魔法の仕組み

上記の実験から判明した仕様を整理すると：

```
【映像の蓄積（自動・無意識）】
念写石を使って念写を行う
　→ 魔紙への転写の有無にかかわらず、その映像が念写石に蓄積される
　→ 術者が意図しなくても蓄積は起きる

【映像の閲覧（意識的操作・同調必須）】
念写石に同調する
　→ 蓄積された映像の「一覧感」が伝わってくる（何枚あるか、どんな映像かの大まかなイメージ）
　→ 閲覧したい映像を意識して選ぶと、その映像が脳に流れてくる
```

### 念写との違い・使い分け

| 操作 | 説明 |
|------|------|
| **念写**（魔紙へ） | 視覚情報を魔紙に焼き付ける。白黒の記録として手渡せる。同調不要 |
| **念写**（念写石経由） | 同上だが、自動的に石内部にも蓄積される |
| **記録魔法**（閲覧） | 念写石に同調し、蓄積映像をカラーで脳内再生する。同調必須 |

念写は「他者に渡せる白黒の記録を作る」、記録魔法は「自分が過去の視覚を見直す」用途。

---

## 閲覧の感覚

念写石に同調して映像を見るとき、術者の主観的な体験は以下のようなものになる。

```
目を閉じると…
　→ 薄い霧の中に複数の「光の塊」が見える感覚（蓄積映像の一覧）
　→ 意識を向けた光の塊が「鮮明になる」ようにフォーカスされる
　→ その映像が脳内に展開される（念写の逆：カラーで見える）
```

これは念視魔法（目型魔石からのリアルタイム映像受信）と似た感覚だが、
「過去の保存映像」を引き出す操作であり、念視より繊細な意識の制御が必要。

---

## 制限と注意点

### 動画は現段階では不可能

念写1回＝静止画1枚の蓄積。
映像の「連続再生（動画）」は、複数の魔石を連続切替するか、
魔法プログラミングで自動制御するまで実現しない。

### 蓄積の上限

| 制限要因 | 内容 |
|---------|------|
| 魔石のサイズ・質 | 大きく質が高い魔石ほど多くの映像を蓄積できる |
| 念写の精度 | 精細な念写ほど1枚のデータ量が多くなる |
| 上限に達すると | 最も古い映像から自然に押し出され、消える（先入れ先出し） |

### 同調の熟練度が必要

念写石に蓄積された映像が多いほど、目当ての映像を選び出す操作が難しくなる。
蓄積量が多い魔石に同調すると、大量の映像の「気配」が一気に流れ込んでくるため、
集中力・同調魔法の技術が低いと目当ての映像を見失う。

## 世界への影響

この技術が広まった場合：

- 目撃証言の代わりに「念写石の記録」が証拠として機能する（裁判・捜査の変革）
- 書物を文字で写さなくても、石に念写して持ち運べる（知識の伝達の革命）
- ただし同調魔法士しか閲覧できないため、現状では主人公個人の能力にとどまる
