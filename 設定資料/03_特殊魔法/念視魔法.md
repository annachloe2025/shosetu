# 念視魔法（ねんしまほう）

## 概要

「遠隔地に設置した目型の魔石から、視界情報を取得する」魔法。
主人公の魔法コンピュータ構想における**部品③：遠隔視覚（監視カメラ相当）**。

**同調魔法の高度な応用であり、主人公専用の魔法である。**

---

## 原理：念写の逆方向

念写魔法と念視魔法は、同じ「視覚情報と魔力の変換」を**逆方向に行う**魔法である。

```
【念写魔法】（既存・一般術者も使用可）
　脳の視覚情報 ──（魔力変換）──→ 魔紙に焼き付く
　　「内から外へ」情報を送り出す

【念視魔法】（新規・主人公専用）
　魔石が捉えた光の情報 ──（魔力変換）──→ 脳で映像として認知する
　　「外から内へ」情報を受け取る
```

念写ができる術者が「逆方向もできるはず」と気づくことが、開発の出発点である。
ただし**念写は生物の魔力に弾かれず無生物（魔紙）に送るだけで済む**のに対し、
念視は**魔石から自分の脳内（生物の内側）へ魔力情報を受け取る**行為であり、
同調魔法の「自分の内部へ外部の魔力情報を取り込む」技術が必要になる。

これが一般術者には不可能で、主人公（同調魔法士）にしかできない理由である。

---

## 目型魔石（めがたまぎし）の構造

通常の魔石を球体に加工し、「目」として機能するように改造したもの。

### 構造

```
　　　　 外光
　　　　　↓
　┌──────────────┐
　│  ╔══╗　　　　　│  ← 光の入口（コーティングなし）
　│  ║光║→→→→→　│
　│  ╚══╝　　　収束点│  ← ここで光が「網膜」として集まる
　│　　　　　　　　　│
　└──────────────┘
　　↑　　　　↑
　コーティング面　この面から外光は入らない
```

| パーツ | 役割 | 現代の対応部位 |
|-------|------|-------------|
| 球体魔石全体 | 眼球 | 眼球 |
| 光の入口部分 | 外光を取り込む | 瞳孔・水晶体 |
| コーティング | 余計な光を遮断 | 強膜（白目） |
| 収束点（球内部） | 光情報が集まる点 | 網膜 |

### コーティング素材

- 光を通さない不透明な素材で球体の大部分を覆う
- 有機魔法（木工系）で加工した繊維を圧縮した素材や、土魔法で焼成した黒色の釉薬が有力
- 重要なのは「光を完全に遮断できること」「魔石表面との馴染ませが可能なこと」

## 修行法：念視の感覚をつかむまで

念写はまず自然に「イメージを外に送る」感覚から始まるが、
念視は「魔石の光情報を脳が受け取る」という、まったく新しい感覚の獲得が必要である。

主人公はこの感覚をつかむために、**専用の修行部屋**を作成する。

### 修行部屋の設計

```
【修行部屋の条件】
・白と黒のコントラストが強い、特徴的なパターンが壁・床・天井に描かれている
・天井にライト（魔力炎等）を設置し、部屋内を均一に明るく照らす
・部屋の中央に目型魔石を設置する台がある
・部屋の大きさは術者が修行に集中できる程度（3〜4m四方程度）
```

なぜ「特徴的なパターン」が必要か：
魔石から視界情報を「受け取れた」かどうかを判定するために、
「見えていれば必ずわかる特徴的な光景」を用意しておく必要がある。
模様のない単色の部屋では、「見えたのか単なる気のせいか」が判別できない。

### 修行の手順

```
Step 1：目型魔石を手で触れ、馴染ませを行う（魔石との基礎接続）

Step 2：目を閉じる
　→ 自分の視覚を完全に遮断することで、魔石からの情報と混在しないようにする

Step 3：念写の逆方向を意識する
　→「魔力を送り出す」のではなく「魔石から情報を引き込む」方向に意識を向ける
　→ 同調魔法の「相手の魔力に接続する」感覚に近い

Step 4：魔石の「収束点」に意識を集中する
　→ 眼球で言えば網膜にあたる球内部の一点

Step 5：成功すると…
　→ 目を閉じているにもかかわらず、部屋の白黒パターンが「見える」感覚が生じる
　→ 最初は輪郭のぼやけた残像のような映像で、訓練とともに鮮明になる
```

### 訓練の難しさ

- 自分の「視覚」と魔石からの「映像信号」が混在し、どちらが何かわからなくなる
- 目を開けたまま魔石の映像を受け取ろうとすると、自分の視覚が優先されて干渉する
- 最初は「なんとなく明暗がわかる」程度から始まり、数ヶ月〜数年の訓練が必要

## 遠隔念視：魔石を離れた場所に設置する

魔石を触れない遠隔地に設置しても念視を行うためには、さらなる技術が必要になる。

### 遠隔接続の仕組み

```
術者 ──（微量の魔力を念話の要領で送る）──→ 遠隔の目型魔石
　　　　　　　　　　　　　　　　　　　　　　↓
　　　　　　　　　　　　　　　魔石が「接続中」状態になる
　　　　　　　　　　　　　　　　　　　　　　↓
術者 ←──（魔石の視界情報が魔力として流れてくる）── 魔石
　　　　　　　　　　　　　　　　　　　　　　↓
　　　　　　　　　　　　　脳が映像として認知する（念視状態）
```

これは念話の「魔力の振動で情報を伝える」原理と同じだが、
伝える情報量が「音声」ではなく「視覚映像」であるため、
**はるかに高い精度・安定性・魔力量**が要求される。

### 遠隔念視の難しさ

| 問題 | 内容 |
|------|------|
| 情報量の巨大さ | 映像情報は音声に比べて情報量が段違いに多い |
| 接続の不安定さ | 魔力の波が乱れると映像が乱れ・途切れる |
| 術者への負荷 | 遠隔視しながら自分で行動することが難しい（二重の意識が必要） |
| 距離の限界 | 念話より射程が短い（情報量が多いほど遠距離への伝達は困難） |

### 術式への刻印

目型魔石に「念視用の術式」を刻印することで、
術者が毎回接続の魔力操作を行わなくても、魔力を流すだけで自動接続できるようになる。

```
術式なし：術者が毎回手動で接続操作 → 高い集中力が必要
術式あり：微量の魔力を流すだけで自動接続 → 日常的な使用が可能になる
```

この術式の設計も、主人公の魔法プログラミングの知識が活きる場面である。

## 実用上の特性

| 項目 | 内容 |
|------|------|
| 解像度 | 目型魔石の精度に依存。球体の加工が精緻なほど鮮明 |
| 色彩 | 原理上はカラーで見える（光そのものを取り込むため） |
| 視野角 | 光入口の大きさと魔石内部の構造による |
| リアルタイム性 | 現在進行形の視界情報を取得できる（録画ではない） |
| 録画との組み合わせ | 念視中の映像を同時に念写・魔石記憶に保存することも可能 |

### 念写との比較

| | 念写 | 念視 |
|--|------|------|
| 方向 | 脳→魔紙（外へ送る） | 魔石→脳（内へ受け取る） |
| 使用者 | 一般術者でも可能 | 同調魔法士のみ |
| 色彩 | 白黒 | カラー（原理上） |
| 対象 | 魔紙（静止した記録） | 脳内（リアルタイム映像） |

## 同調魔法との関係

念視は表面的には「感知系の応用」に見えるが、
本質は**同調魔法の「外部の魔力状態を自分の内部で認知する」能力の極限応用**である。

```
同調魔法（基本）：他者の魔力の状態を自分の感覚で認知する
　　↓
念視魔法（応用）：魔石が捉えた光情報を、自分の視覚として認知する
```

一般の感知系術者は「魔力の状態」を感知できるが、
「光情報を視覚映像として変換して脳に届ける」という精密な操作は同調魔法なしには不可能。

## 主人公魔法のロードマップ上の位置

```
✅ STEP 1: 念写魔法（カメラ・スキャナー）
✅ STEP 1.5: 念視魔法（監視カメラ） ← 今回
🔲 STEP 2: 魔石記憶（ストレージ）
🔲 STEP 3: 魔法プログラミング（ソフトウェア）
🔲 STEP 4: 魔石ネットワーク（インターネット）
🔲 STEP 5: 魔石サーバー（クラウド）
```

念視は独立したSTEPというより、念写の習得直後に「逆方向もできる」と気づいて開発する。
物語上は念写の直後に、より短い訓練で習得できる描写になる予定。
