# 技術体系と車輪の不在

## 核心設定

**この世界には車輪という概念が存在しない。**

車輪だけでなく、回転運動を利用する機構（滑車・歯車・水車・轆轤・糸車など）が一切発明されていない。現実世界の文明が車輪を起点に発展させた技術体系は、この世界ではすべて**魔法によって代替**されている。

---

## 文明が育たない根本原因：スタンピードによる定期的破壊

この世界の技術水準が中世レベルに留まっている理由は、2つの構造的要因による。

### ① スタンピードによる文明のリセット

定期的に発生する大規模スタンピード（[[スタンピード詳細]] 参照）が、蓄積された文明を繰り返し破壊する。

- 都市・インフラ・工房・書庫が物理的に壊される
- 技術を持つ職人・学者が死亡し、知識の継承が断絶する
- 復興に何十年もかかり、次のスタンピードまでに元の水準に戻るのが精一杯

**機械技術のような「積み上げ型の技術」は特に脆い。** 車輪→歯車→時計→精密機械という技術の連鎖は、安定した数百年が必要だが、スタンピードがそれを許さない。

### ② 魔法による補完：文明がなくても生きていける

一方で魔法は**個人の身体に宿る能力**であり、インフラが壊れても失われない。

- 建物が全壊しても、土魔法使いが生き残っていればまた建てられる
- 道具や工房が失われても、魔法の技術は人から人へ直接伝えられる
- 機械なしでも、魔法で食料生産・建築・製造・輸送が成立する

つまり**魔法は「文明が破壊されても残る技術基盤」**として機能している。

### この2つが生む構造

```
スタンピードで文明が破壊される
　↓
魔法があるから、機械技術なしでも復興できる
　↓
機械技術を開発する動機が生まれない
　↓
次のスタンピードでまた破壊される
　↓
（繰り返し）
```

→ 結果として**魔法に全面依存した中世レベルの技術体系**が固定化された。
これは「遅れている」のではなく、**この世界の環境に最適化された技術体系**である。

## 発明されなかったもの

### 車輪と回転機構

現実世界で車輪が発明された動機は「少ない力で重いものを動かす」という機械的優位の獲得だった。この世界ではその問題を**魔法が先に解決してしまった**ため、車輪を発明する動機が生まれなかった。

具体的には：

- 重いものを動かしたい → 土魔法の馴染ませ＋操作、または強化魔法で身体能力を増強
- 繊維を加工したい → 有機魔法（織物系）で直接操作
- 粘土を成形したい → 土魔法で直接成形
- 水を汲み上げたい → 水魔法で直接誘導
- 穀物を挽きたい → 土魔法で粉砕

**回転運動による機械的優位**という発想自体が、この世界の知性体の思考に存在しない。

### 機械式時計

歯車が存在しないため、機械式時計は作れない。時間の把握は**鐘と太陽**による：

**日中の時間管理：5回の鐘**
| 鐘 | タイミング | 役割 |
|----|-----------|------|
| 日の出の鐘 | 日の出 | 起床・活動開始 |
| 午前の鐘 | 日の出から正午の中間 | 労働の区切り |
| 正午の鐘 | 太陽が最も高い時 | 昼食・休憩 |
| 午後の鐘 | 正午から日没の中間 | 午後の労働の区切り |
| 夕方の鐘 | 日没前 | 活動終了・帰宅 |

- 鐘を鳴らすのは都市の鐘楼の番人。太陽の位置を見て判断する
- 季節によって間隔が変わる（夏は長く、冬は短い）
- **夜の鐘はない。** 夜は「眠る時間」であり、細かい時間管理は不要
- 夜番（城壁の見張り等）のみ水時計を使う（軍事・内部用途限定）
- その他の補助手段：日時計（晴天時）、火魔法の術式石（一定時間で消える仕組み）

→ 「正確な時刻」という概念が曖昧で、生活は太陽の動きと鐘に強く縛られる。

### レンズ・光学機器

感知魔法が遠距離探知を、念視魔法が遠隔視覚を提供するため、望遠鏡・顕微鏡を発明する動機がない。

- **微生物の存在を誰も知らない**。疫病の原因は「魔力の乱れ」「瘴気」と説明される
- 眼鏡も存在しない。視力低下は強化魔法や薬草で対処（無魔人は対処困難）
- 光学という学問分野自体が存在しない

### 物理的な錠前

感知魔法と術式石封印が防犯の主力。

- 貴族・商人の金庫は専用の術式石で封印。解除には所有者のマーキング済み魔力を流し込む必要がある
- 無魔人は術式石封印を自力でかけられず、魔石持ちに依頼するか閂（かんぬき）に頼る
- 金属加工による精密な鍵・錠前の技術は未発達

### 石鹸・化学的洗浄剤

水魔法で汚れを直接除去できるため、化学的な洗浄技術の開発動機が弱い。

- ただし天然の洗浄剤として**泡実（あわみ）の木**の実が広く利用されている
  - 泡実の実にはサポニン（天然の界面活性剤）が含まれ、水に溶かすと泡立つ
  - 無魔人でも使える洗浄手段として全階層で普及
  - 実を乾燥・加工して固形石鹸のように使うことも可能
- 衛生面の格差は水魔法の有無で生じるが、泡実のおかげで無魔人も最低限の清潔は保てる

## 車輪の代替技術一覧

### 輸送：そり

車輪付きの荷車の代わりに、**そり・家畜獣・水運**が陸上輸送の柱。

| 手段 | 内容 |
|------|------|
| そり | 家畜馬が牽引。軽〜中量の荷物運搬に使用 |
| 荷竜（にりゅう） | ステゴサウルス型の大型爬虫類家畜。背に荷籠を積み1〜2トン運搬可能。車輪なき世界の「トラック」 |
| 走鳥（そうちょう） | ダチョウ型の大型鳥類家畜。騎乗用。短距離で馬より速く、悪路・山道に強い |
| 家畜馬 | 騎乗・軽荷役・そり牽引・早馬通信 |
| 水運 | 大河・海の船。最も効率的な大量輸送手段 |

**そり道**は各集落・都市間を結ぶ主要インフラ。土魔法使いが定期的に路面を平滑化・硬化させて維持管理する。これは土魔法使いの重要な公共的役割の一つであり、各国で「土守（つちもり）」と呼ばれる専門職が存在する。そり道の維持は土守の仕事の一部であり、建築・水路・防壁の維持管理なども担う。

**家畜化**は魔物から魔石を摘出して従順化させる技術。野生動物はすべて魔物であるため、家畜はすべてこのプロセスを経ている。荷竜の保有数は商人ギルドの力の指標でもある。

詳細は [[交通と物流]] を参照。

### 陶芸：土魔法による直接成形

轆轤（ろくろ）の代わりに、土魔法で粘土を直接成形する。

- 術者が両手で粘土を持ち、土魔法で内部から形を整える
- 回転させる必要がないため、左右非対称の複雑な形状も作りやすい
- 大量生産には向かないが、一つ一つの品質は高い
- 無魔人の陶工は手びねり・型押しで成形する（技術的に可能だが効率で劣る）

### 紡績・織物：有機魔法（織物系）による繊維操作

糸車・織機の代わりに、有機魔法（織物系）で繊維を直接操作する（`衣文化.md` で設定済み）。

- 有機魔法（織物系）使いが繊維の整列・撚り・織りを魔法で行う
- 品質は術者の腕次第（高級品〜庶民品の差は `衣文化.md` 参照）
- 無魔人は手作業で糸を撚り、手織りを行う

### 製粉：土魔法による粉砕

水車・石臼の回転機構の代わりに、土魔法で穀物を直接粉砕する。

- 穀物を石の容器に入れ、土魔法で上から圧縮して粉にする
- または穀物を土魔法で「軟化」させてから手作業で潰す（低コスト）
- 大規模な製粉は土魔法使いが専業で行う「粉屋」が担当
- 無魔人の家庭では杵と臼で手作業（現実世界の原始的な製粉と同様）

### 建築：土魔法の馴染ませ＋操作

滑車・クレーンの代わりに、土魔法で石材・建材を移動する（`土魔法.md` で設定済み）。

- 前日に馴染ませ → 翌日に操作、という計画的な工程
- 大規模建設では複数の土魔法使いが分業して連携
- 木材の加工は有機魔法（木工系）で繊維を操作して切断・接合

### 揚水・灌漑：土魔法＋水魔法の連携

水車の代わりに、魔法で水を直接汲み上げ・誘導する。

- 井戸からの汲み上げは水魔法の基本技術
- 都市の給水は水魔法使いが管理する給水路
- 灌漑の水路・ため池は土守（土魔法使い）が土木工事で敷設、水の管理は水魔法使いが担当

## 技術的な影響

### 存在しないもの

- 車輪付きの乗り物（馬車・荷車・戦車）
- 歯車を使った機構（時計・風車・水車）
- 滑車を使った建設機械（クレーン）
- 轆轤（陶芸用・旋盤用）
- 糸車・紡ぎ車
- 回転式の石臼

### 存在するもの（車輪なしで成立する技術）

- そり（陸上輸送の主力）
- 船（水魔法による推進。河川用のみ。海は魔物の領域のため航海不可能）
- 弓・弩（弾性を利用した投射武器。回転不要）
- 鍛冶（火魔法＋手作業。ふいご＝風魔法で代替）
- 建築（土魔法＋人力。`土魔法.md` 参照）
- 農業（土魔法＋水魔法＋人力。`食文化.md` 参照）
- 製紙（水魔法が主導。パルプ化は有機魔法（木工系）。`水魔法.md` 参照）

## 無魔人への影響

車輪の不在は**無魔人にとって特に不利に働く**。

魔石持ちは魔法で車輪の機能を代替できるが、無魔人には代替手段がない。現実世界なら車輪という「誰でも使える技術」で解決できた問題が、この世界では「魔法を使えるかどうか」で解決可否が分かれる。

| 作業 | 魔石持ち | 無魔人 |
|------|---------|--------|
| 重量物の運搬 | 土魔法＋強化魔法 | 人力のみ。家畜の力に頼る |
| 製粉 | 土魔法で粉砕 | 杵と臼で手作業（重労働） |
| 陶器製作 | 土魔法で成形 | 手びねり・型押し（品質で劣る） |
| 紡績 | 有機魔法（織物系） | 手撚り・手織り（時間がかかる） |
| 水の汲み上げ | 水魔法 | 縄と桶で手作業 |

→ **車輪がない世界では、魔法の有無が生活の質に直結する格差構造**がより強固になる。
これは「魔石持ち vs 無魔人」の社会的格差を裏づける技術的根拠でもある。

## 物語での活用

- 「車輪がない」ことは作中で特筆されない（住人にとっては当たり前のこと）
- 転生者である主人公だけが「車輪がない」ことに気づく可能性がある
  - ただし車輪の導入は簡単ではない（道路インフラがそり前提で整備されている）
  - 技術革命の種として後半で活用する可能性あり（要検討）
