# 教育制度と娯楽

## 教育制度の全体像

### 教育が充実する理由：教育＝国防

魔物の脅威が常にある世界では、**教育は「教養」ではなく「生存」のためにある。**

- 全国民が最低限の自衛能力を持つ必要がある
- スタンピード時には総動員される → 無魔人も後方支援や避難誘導を担う
- 鍛冶師・建築師・感知士などの専門職は戦力に直結 → 国家レベルで育成する価値がある
- **「教育に投資しない国は滅ぶ」がこの世界の共通認識**

### 無魔人の教育可能性

無魔人は主魔石を持たないが、体組織全体で極めて弱いマーキング能力が残っている（[[魔力分子とマーキング]]）。属性遺伝子の発現は事実上できないため**直接の属性魔法（火を起こす・水を生むなど）はほぼ不可**だが、訓練すれば以下のことが可能である：
- 既に魔石持ちが起こした現象の延命・微調整（火を少しだけ持たせる、水面の波を抑えるなど）
- 既に術式が刻まれた**術式石の駆動補助**（数人がかりで触れて魔力を流し込む）
- 家畜・農地・道具に対する弱いマーキングの補助作業

このため、無魔人を教育する意味がある。これらの補助魔力運用を上手く使えるかどうかで、
無魔人の中でも能力差が出る。

## 基礎教育（義務教育に相当）

### 概要

| 項目 | 内容 |
|------|------|
| 対象 | 全国民の子供（魔石持ち・無魔人を問わない） |
| 期間 | 6〜10歳の4年間程度 |
| 設置場所 | 都市では**区学舎（くがくしゃ）**、農村では**村学舎** |

### 教科と内容

| 科目 | 内容 | 重要性 |
|------|------|--------|
| 読み書き・算術 | 基礎的な識字と計算 | 商業にも戦闘にも必要 |
| 魔物知識 | 危険な魔物の見分け方・遭遇時の対処法 | 生死に関わる必修科目 |
| 基礎魔法操作 | 微量の魔力の制御法。無魔人にも教える | 無魔人の能力向上 |
| 身体訓練 | 走る・投げる・避ける。最低限の身体能力 | 生存スキル |
| 生活技能 | 火の起こし方・応急手当・薬草の基礎知識 | 実用的な知識 |

### 識字率への影響

基礎教育の義務化により、**識字率はこの世界では意外と高い。**

理由：読み書きができないと魔物情報や避難指示が理解できないため、
国家が識字教育を推進している。

## 専門教育の分岐

基礎教育を終えた10歳以降、魔石持ちと無魔人の進路が分かれる。

### 魔石持ちの専門教育（10歳〜）

魔力検査で魔石が確認された子供の主な進路：

| 進路 | 対象 | 内容 | 詳細 |
|------|------|------|------|
| 辺境学舎 | 孤児・辺境の子供 | 戦闘＋生活魔法の実践教育 | 詳しくは `孤児院と戦闘学校.md` 参照 |
| 王立魔法騎士学院 | 貴族・有力家の子弟 | エリート養成。高度な魔法＋軍事＋統治 | 詳しくは `貴族学校.md` 参照 |
| 徒弟制度 | 一般庶民の魔石持ち | 専門職の師匠に弟子入り。実地で学ぶ | 以下参照 |

#### 徒弟制度の詳細

- **開始年齢**：10歳前後
- **対象**：一般庶民の魔石持ち
- **師匠**：職人の元に弟子入り。師匠が魔法と技術の両方を教える
- **入門儀式**：弟子入りの際に礼金（または労働奉仕）を師匠に納める
- **修業年数**：職種による（鍛冶：5〜7年、建築：4〜6年、織布：3〜5年など）
- **卒業**：一人前と認められると**職人証**が発行され、独立して営業できる

### 無魔人の専門教育（10歳〜）

無魔人にも基礎教育の後の進路がある：

| 進路 | 内容 |
|------|------|
| 農業・牧畜見習い | 親元または近隣農家で実地。最も一般的 |
| 商人見習い | 商家や商人ギルドに弟子入り。算術・交渉・流通を学ぶ |
| 職人補助見習い | 魔法職人の補助作業を学ぶ（大工補助・荷役・素材加工など） |
| 薬草師見習い | 薬草の採集・調合を学ぶ。魔法不要の重要職 |
| 兵站・後方支援要員 | 軍の後方支援を担う訓練。補給・荷運び・野営設営など |

## 国家プロジェクトとしての育成

以下の職種は国の防衛・インフラに直結するため、
**国家が費用を負担して育成する**ケースがある。

| 職種 | 理由 |
|------|------|
| 戦闘系魔法使い | スタンピード防衛の最前線。最優先 |
| 鍛冶師（火魔法） | 武器・防具の製造。戦力の根幹 |
| 建築師（土魔法） | 防壁・要塞の建設と修復。スタンピード後の復興 |
| 感知士 | 感知の塔での警戒・早期警戒網の維持。最重要インフラ |
| 土守（土魔法） | 建築・水路・防壁・街道の維持。インフラの要 |

**優秀な適性を持つ子供が貧しい家庭の出身でも、国家が学費を出して育てることがある。**
これは慈善ではなく**国防投資**。特にコンコルディア盟邦ではこの傾向が強い。

## 識字率

| 階層 | 識字率 | 理由 |
|------|--------|------|
| 貴族 | 非常に高い | 教養の証。統治に必要 |
| 魔石持ちの庶民 | 高い | 基礎教育＋術式理解に必要 |
| 都市の無魔人 | 中〜高 | 基礎教育＋商業に必要 |
| 農村の無魔人 | 中程度 | 基礎教育で最低限は学ぶ。ただし使う機会が少なく忘れる人も |

**現実の中世より識字率はかなり高い。** 基礎教育の義務化と、
魔物対策の情報伝達の必要性が理由。

## 知識の保存と断絶

スタンピードで書庫が焼かれ、学者が死ぬことで知識が失われることは稀ではない。

- **口伝が最も強い知識伝達手段**（人が生き残れば伝わる）
- 書物は贅沢品。大量の紙は水魔法使い・有機魔法（木工系）使いの手間がかかる
- **古竜ヴァルナディアが人類に歴史を教えた**のは、人類自身が歴史を保持できなかったから
- スタンピードのたびに「再発見」される技術もある
- **教育制度が充実しているのは、知識の断絶を防ぐ意味もある**

## 娯楽

### 音楽

- 楽器は存在する（弦楽器・管楽器・打楽器。いずれも車輪不要の技術）
- 風魔法使いが音を増幅・操作できるため、**魔法と音楽の融合**がある
  - 風魔法使いの歌い手は声を遠くまで届けられる
  - 音の反響を操作して「音響効果」を生む
- 庶民の娯楽として広場での演奏会・歌が一般的
- 貴族は専属の楽師を雇う

### 語り部・物語

- **最も広く普及した娯楽**
- 語り部が都市を巡回し、英雄譚・歴史・伝説を語る
- 酒場での語り部の出番は夜の主要な娯楽
- 語り部は同時に情報の伝達者でもある（他の都市の噂を運ぶ）

### 酒場

- 庶民の社交の中心
- 酒・食事・語り部・賭け事が揃う
- 冒険者・商人・職人が集まる情報交換の場
- 都市の各区画に数軒はある

### スポーツ・競技

| 競技 | 説明 |
|------|------|
| 模擬戦 | 魔法使い同士の試合。専用の競技場（石造りの囲い）で行う。貴族・軍人に人気 |
| 走鳥レース | 走鳥の速さを競う。庶民にも人気 |
| 射的 | 弓・弩の腕前を競う |
| 力比べ | 強化魔法の使い方を競う腕相撲・石持ち上げ |

### 入浴

- 入浴は娯楽・社交の一環でもある
- 都市の公衆浴場は社交場として機能

### 賭け事

- 走鳥レース・模擬戦に賭けるのが一般的
- 賭場（賭博場）は都市部に存在。合法・違法は国による
- 無魔人にとっても参加できる数少ない「平等な」娯楽

## 年中行事・祭り

### 収穫祭

- 秋の収穫を祝う最大の祭り。3国共通で行われる
- 食料の豊作を感謝し、冬に備える
- **農村**：村全体で食卓を囲む。踊りと歌
- **都市**：市場が特別価格で開放。屋台・演奏会・模擬戦

### スタンピード追悼祭

- 過去のスタンピードの犠牲者を悼む祭り
- 各国で時期が異なる（最も被害が大きかったスタンピードの時期に合わせる）
- 火を灯して「魔力を天に還す」儀式を行う
- 防衛の誓いを新たにする意味合いも持つ

### 魔力検査の日

- **6歳（基礎教育の入学時）** に全員一斉に魔力検査を行う公式行事
- 検査は区学舎・村学舎の入学手続きとセットで実施される
- 国家が配備する「**魔力検査盤**」（属性魔石に検査術式を刻印した国家資産。詳細は「[[魔力検査]]」参照）を使用。巡回検査官が各学舎を回って持ち込む
- 6歳で検査する理由：基礎教育の開始と同時に行うことで、魔石持ちには入学直後から適切な教育を施せる。入学後1年間も検査しないのは非合理的なため
- 検査項目：魔石の有無、4大属性の分布、魔力量の概算、同調魔法の疑いの有無
- 家族にとっては「子供の未来が決まる日」であり、期待と不安が入り混じる
- 魔石が見つかった場合も、**基礎教育は10歳まで継続**する。その間に系統適性の把握と進路の準備を行う（系統適性は各系統の魔法を実際に試させる実地試験で確認する）

### 竜神殿の祭日

- ヴァルナディア（友好的古竜）を祀る竜神殿の祭日
- 竜貨の鋳造・配布が行われる
- 竜神殿への巡礼が盛んな時期

### 冬至・夏至

- 太陽の動きが時間の基準であるこの世界では、冬至と夏至は重要な節目
- **冬至**：「最も暗い日」。火を灯して夜を照らす祭り。春の到来を祈る
- **夏至**：「最も長い日」。水辺で涼を取り、夏の恵みを祝う

## 子供の遊び

- **石投げ**：土魔法で石を飛ばす遊び（魔石持ちの子供）
- **追いかけっこ**：強化魔法を使って走る版（魔石持ち）
- **人形遊び**：有機魔法で草人形を動かす
- **マーキング遊び**：無魔人の子供も、魔石持ちの子が起こした小さな火や水の揺れを、触れて延命させる・弱く誘導するといった補助遊びに参加する

### 多様な背景を持つ子供の交流

**基礎教育で一緒に学ぶため、魔石持ちと無魔人の子供が一緒に遊ぶのは普通。**
ただし専門教育に進む10歳以降は自然と交流が減る傾向がある。
