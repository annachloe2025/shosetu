# 交通と物流

この世界では車輪が存在しないため、陸上輸送は家畜獣とそりに大きく依存する。水運と飛行が補完的役割を果たし、これら複数の手段の組み合わせが移動と物流体系を支えている。大型家畜の存在が陸上物流のボトルネックを大きく緩和する一方で、それらの飼育コストと魔法依存性が経済構造を形作っている。

---

## 家畜の概要

この世界の野生動物はすべて魔物であるが、人類は古くから特定の魔物を捕獲し、**魔石を除去することで従順化**させて家畜として利用してきた。

### 家畜化のプロセス

1. 若い個体（幼獣）を捕獲する
2. 魔石を摘出する → 魔力を失い攻撃性が大幅に低下
3. 調教する（魔石がないため人間への敵意がほぼなくなる）
4. 繁殖させて世代を重ねる → 家畜として安定した系統を確立

**→ 魔石の摘出が家畜化の核心技術。** これがなければ魔物は従順にならない。
家畜化に成功した種はごく一部だが、それが人類の文明を支えている。

## 家畜の種類

### 家畜馬（汎用の乗用・軽荷役）

| 項目 | 内容 |
|------|------|
| 原種 | 馬型魔物（Dランク程度） |
| 体格 | 現実の馬とほぼ同等 |
| 用途 | 騎乗・軽荷役・そり牽引・早馬（通信） |
| 特徴 | 最も広く飼育されている家畜。調教が容易 |

- 鐙（あぶみ）は存在する（車輪とは無関係の技術）
- 強化魔法をかけて持久力・速度を向上させることが可能
- 軍馬は選別された大型個体に強化魔法を施したもの

### 荷竜（にりゅう）── 大型爬虫類の荷役獣

| 項目 | 内容 |
|------|------|
| 原種 | 大型爬虫類魔物（Cランク程度） |
| 体格 | 体長5〜7m。背の高さ2.5〜3m。重量2〜3トン |
| 外見 | ステゴサウルスに似た巨大な四足歩行のトカゲ。背中に骨板の列がある |
| 用途 | 大量の荷物運搬。車輪なき世界の「トラック」 |
| 性格 | 魔石を摘出すると非常に温厚。動きは遅いが力強い |

**荷竜の運用：**
- 背中の骨板の間に**荷籠（にかご）**を固定して荷物を積む
- 一頭で1〜2トンの荷物を運搬可能（そりの何倍もの積載量）
- 速度は遅い（時速4〜6km）が、休まず長時間歩ける
- 飼育コストが高い（大量の飼料が必要）ため、商人ギルドや国家が主に保有
- 都市間の大量物資輸送の主力
- 複数頭を連ねて**荷竜隊**として運用するのが一般的

**荷竜がいる理由：**
車輪がないこの世界では、そりだけでは大量輸送が難しい。
荷竜の存在が陸上物流のボトルネックを大きく緩和している。
ただし、荷竜は飼育に手間とコストがかかるため、個人所有は現実的でない。
→ 荷竜を保有する商人ギルドの影響力が大きい一因でもある。

### 走鳥（そうちょう）── 大型鳥類の騎乗獣

| 項目 | 内容 |
|------|------|
| 原種 | 大型走鳥類魔物（D〜Cランク程度） |
| 体格 | 体高2〜2.5m。体重150〜250kg |
| 外見 | ダチョウに似た飛べない大型の鳥。脚力が強い |
| 用途 | 騎乗（馬より速い短距離移動）。軽い荷物の運搬 |
| 性格 | 馬より気性が荒いが、訓練すれば乗りこなせる |

**走鳥の特徴：**
- 馬より**短距離での加速が速い**（時速50〜60km程度の疾走が可能）
- ただし持久力は馬に劣る（全力疾走は1時間程度が限界）
- 二足歩行のため、**悪路や山道に強い**（そりが通れない場所でも移動可能）
- 荷物の積載量は少ない（騎手＋軽荷物程度）
- 馬よりも飼料が少なくて済む（雑食性）

**用途の棲み分け：**
| 状況 | 最適な家畜 |
|------|-----------|
| 長距離の安定した移動 | 家畜馬 |
| 短距離の高速移動 | 走鳥 |
| 大量の荷物運搬 | 荷竜 |
| 悪路・山道の移動 | 走鳥 |
| そりの牽引 | 家畜馬 |
| 早馬（通信リレー） | 家畜馬 or 走鳥（区間による） |

### その他の家畜

- **家畜牛**：乳・肉・皮革用。荷役にも使えるが荷竜より効率が悪い
- **家畜羊**：毛・肉用
- **家畜鶏**：卵・肉用
- **家畜犬**：番犬・狩猟補助

## 陸上移動

### そり（軽〜中量の陸上輸送）

| 種類 | 用途 | 牽引 |
|------|------|------|
| 人力そり | 農村内の短距離運搬 | 人力。強化魔法で補助 |
| 家畜そり | 都市間の荷物運搬 | 家畜馬1〜2頭 |
| 大型そり | 商隊の中量輸送 | 家畜馬4〜6頭。複数のそりを連結 |
| 軍用そり | 兵站・武器輸送 | 家畜馬＋強化魔法。護衛付き |

**そりの限界：**
- 車輪付き荷車に比べると積載効率が劣る
- 路面状態に大きく左右される（泥濘では使えない）
- 冬季（凍結路面）が最も効率が良い季節

→ **大量輸送は荷竜、軽〜中量輸送はそり** という棲み分け。

### そり道

- 土魔法使い（土守）が路面を平滑化・硬化させた「そり道」が主要街道
- **土守（つちもり）**は各国で公的な役職。国家が雇用し、街道・建築・水路・防壁の維持管理を担当。そり道の整備はその仕事の一部
- そり道の品質：
  - 主要街道（都市間）：高品質。定期的に整備。荷竜も通行可能な幅
  - 支線（都市〜農村）：中品質。整備頻度が低い。荷竜は通れないこともある
  - 農村間の小道：未整備。自然の地面のまま

### 移動速度の目安

| 手段 | 速度 | 1日の移動距離 |
|------|------|-------------|
| 徒歩 | 時速4〜5km | 20〜30km |
| 家畜馬（騎乗） | 時速10〜15km | 50〜80km |
| 走鳥（騎乗） | 巡航 時速15〜20km / 疾走 時速50〜60km | 40〜60km（持久力の制約） |
| 家畜そり（荷物あり） | 時速8〜12km | 40〜60km |
| 荷竜隊（大量輸送） | 時速4〜6km | 25〜40km |
| 飛行（風魔法使い） | 時速80〜200km | 数百km（魔力による制限） |

## 水運

### 河川の船

- **大河とその支流が大陸の動脈**
- 特にドミナトゥス帝国では水運が交易の主力
- 水魔法使いの推進で上流にも遡れる
  - 下りは流れに任せる。上りは水魔法使いが水流を操作して推進
- 筏（いかだ）：最も簡素。木材を有機魔法（木工系）で組んで流す
- 平底船：河川用の浅い喫水の船。荷物運搬に特化
- 大型船：大河の中流〜下流で使用。商人ギルドが運営

**水運の優位性：**
車輪がないこの世界では、水運の相対的な重要性が現実の中世以上に高い。
大河に面した都市は物流の要衝として繁栄し、面していない都市は荷竜に頼る。

### 海について

- 海は魔物が棲息する危険地帯であり、**航海は不可能**
- 沿岸部でさえ海の魔物が出没するため、漁業も極めて限定的
- 東の海はルクスマーレ王国の東端に広がるが、交通路としては機能しない
- 海は人類にとって「行き止まり」であり、大陸の外に出る手段は存在しない

## 空の移動

### 飛行（風魔法使い限定の特権）

- 強化系魔法の翼型魔防壁で揚力面を展開し、風魔法で推進する
- 消費：時速80〜120kmで80〜120MP/時間
- **魔石持ちの風魔法適性者だけが使える超レアな移動手段**
- 軍事偵察・緊急連絡・VIPの護衛移動に使われる
- 一般人が飛行で移動することはまずない

## 旅の実態

### 街道の危険

- **魔物の出没**が旅の最大のリスク
- 街道沿いでもDランク〜Cランクの魔物が出る可能性がある
- 主要街道は定期的に討伐隊が巡回するが、完全な安全は保証されない
- 支線・農村間の小道はほぼ自己責任

### 旅人の構成

| 種類 | 移動手段 | 護衛 |
|------|---------|------|
| 商隊 | 荷竜隊＋大型そり | 雇われ護衛（魔法使い・戦士） |
| 使者 | 家畜馬 or 走鳥 | 単独 or 少数精鋭 |
| 冒険者 | 徒歩 or 走鳥 | 自力（パーティ） |
| 一般人 | 商隊に同行 | 商隊の護衛に頼る |
| 貴族 | そり or 飛行 | 専属の護衛隊 |

**一般人が一人で旅をすることはほぼない。** 商隊に同行させてもらうか、複数人でまとまって移動する。

### 宿泊

- 都市間の街道沿いに**宿場（やどば）**が点在
- 宿場の設備：
  - 宿屋（寝床＋食事）
  - 馬屋・荷竜舎（家畜の休憩・飼料・強化魔法での疲労回復）
  - 防壁（石積みの囲い＋魔物忌避香を焚く術式石による夜間防御）
- 野営する場合は、魔法使いが交代で不寝番を立て、魔物忌避香を焚き続ける
  - 不寝番なしの野営は自殺行為

### 山越え

- 東方魔泉山脈・西方魔泉山脈を越える峠道は、旅の最難関
- 山脈は魔力が高く、魔物も強い
- 峠道沿いに要塞化された宿場が点在（両国が共同管理）
- 冬季は雪で閉鎖されることもある
- 荷竜は峠道が通れないことがある → **走鳥に荷を分散して山越え**する
- **峠の通行税**が両国の重要な財源

## 物流の仕組み

### 商人ギルド

- 都市間の物流は**商人ギルド**が組織的に管理
- ギルドが護衛の手配・そり道の利用調整・荷物の保険を提供
- 商隊の定期便が都市間を結ぶ（現実世界のキャラバンに相当）
- **荷竜の保有数がギルドの力の指標**。大手ギルドほど多くの荷竜を抱える

### 輸送手段の棲み分け

| 輸送手段 | 適する荷物 | 適する距離 |
|---------|-----------|-----------|
| 荷竜隊 | 大量の穀物・木材・鉱石 | 中〜長距離（陸路） |
| 家畜そり | 中量の雑貨・交易品 | 短〜中距離（陸路） |
| 走鳥 | 軽量高価値品・急ぎの荷 | 短〜中距離（悪路含む） |
| 河川船 | 大量のあらゆる荷物 | 大河沿い（最も効率的） |
| ※海上船は存在しない | — | 海は魔物の領域であり航海不可能 |

### 各国の物流特性

| 国 | 主力輸送 | 特徴 |
|----|---------|------|
| ドミナトゥス帝国 | 大河の水運＋荷竜隊 | 大河が国の動脈。荷竜は河から離れた地域を補完 |
| ルクスマーレ王国 | 河川＋荷竜隊 | 山脈からの河川を活用。国内は河川と荷竜が主力 |
| コンコルディア盟邦 | 荷竜隊＋そり | 大河へのアクセスが限定的。荷竜への依存度が最も高い |
