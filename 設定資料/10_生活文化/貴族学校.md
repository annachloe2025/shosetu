# 貴族学校（王立魔法騎士学院）

## 概要

正式名称は各国により異なるが、ここでは仮に**「王立魔法騎士学院」**と呼ぶ。
王都に設置された、貴族子弟が通う国家公認の教育機関。

> 辺境学舎が「孤児を戦力として育てる生存の場」であるのに対し、
> 貴族学院は「次世代の指導者・将校を育てる養成機関」である。

---

## 対象と入学資格

**原則として貴族（魔石公認保有者）の子弟が対象。**

| 対象 | 条件 |
|------|------|
| 王族・上位貴族の子弟 | 当然の権利として入学 |
| 下位貴族（男爵・騎士）の子弟 | 爵位があれば入学可 |
| 魔石持ち平民（特例枠） | 辺境での著しい戦功・または領主の推薦状が必要 |

特例枠は非常に狭く、学院内での立場も当初は低いことが多い。
しかし実力で頭角を現した特例入学者が後に重用される例もある。

---

## 入学年齢・修業年限

- **入学：10歳**（成人前の教育を集中して行う）
- **卒業：15歳**（同時に成人と見なされる）
- 修業年限：5年間

> 辺境学舎と同じく10〜15歳の年齢帯だが、内容は大きく異なる。

## カリキュラム

### 全員共通科目

| 科目 | 内容 |
|------|------|
| 魔法実技 | 自分の魔石適性の見極め・魔力制御・各系統の基礎術式 |
| 剣術・体術 | 魔法と組み合わせた近接戦闘。防衛の基本 |
| 魔物学 | 魔物の種類・生態・弱点・スタンピード対応の基礎 |
| 歴史・地政学 | 6つの時代・3国の成立・辺境の意義 |
| 読み書き・計算 | 将来の領地運営・外交に必要な知識 |

### 選択・専門科目（上位学年）

| 科目 | 対象 |
|------|------|
| 指揮・戦略論 | 将来の騎士団長・辺境伯候補 |
| 外交・政治学 | 王族・公爵家の子弟 |
| 術式応用 | 術式魔法の発展（術式師候補） |
| 感知・情報魔法 | 感知系適性者向け（斥候・情報参謀候補） |
| 医療・薬学 | 同調魔法適性者や支援型志望者向け |

## 王族の扱い

王族は原則として学院に在籍するが、**個別カリキュラムが加わる**。

```
【王族の追加教育】
・国家統治・法制度の理解
・他国との外交史・現状分析
・王宮付きの導師による個別指導
・上位学年になると政務への同席（見習いとして）
```

王族は同じ学院に通いながらも、別格の立場に置かれる。
普通の授業は他の生徒と同じクラスで受けることが多く、
これが貴族子弟と王族が横のつながりを持つ機会になっている。

---

## 学院の雰囲気・人間関係

**上位貴族と下位貴族の格差が如実に出る場所**でもある。

```
【よくある人間関係の構図】
・公爵家・辺境伯家の子弟 → 将来のエリートとして周囲が気を遣う
・男爵家・騎士爵の子弟 → 数が多い。実力で存在感を示そうとする
・特例入学の魔石持ち平民 → 身分差から疎外されがちだが、実力次第で尊重される
・王族 → 圧倒的な別格。接し方に迷う生徒が多い
```

魔法の実力は客観的に測られるため、出自より魔力が如実に序列を作ることも。
魔力が高い下位貴族が上位貴族の子弟を授業で超えることは珍しくない。

---

## 地方の類似機関

王都の王立学院は最大規模・最高水準だが、各地の大都市にも同種の学院が存在する。

- 内陸の伯爵領：規模は小さいが王都学院と同等のカリキュラム
- 辺境の伯爵・辺境伯領：実戦色が非常に強い。野外訓練・実際の魔物討伐への同行も
- 辺境の学院は「辺境学舎の上位版」に近い性格を持つこともある

## 辺境学舎との比較

| 項目 | 王立魔法騎士学院 | 辺境学舎 |
|------|---------------|---------|
| 対象 | 貴族子弟（一部特例） | 孤児・貧困層 |
| 場所 | 王都・大都市 | 辺境・各地 |
| 目的 | 指導者・将校の養成 | 次世代戦力の育成 |
| 雰囲気 | 教育的・政治的 | 軍事的・生存的 |
| 卒業後 | 騎士団指揮・領地継承・政務 | 騎士団一般兵・職人・農業 |
| 格差 | 爵位・家格による格差がある | 魔石有無によるコース差 |

## 物語上の役割

主人公（王族）が通う場所として、以下の描写が可能：

- **世界観の解説**：歴史・魔法・魔物の授業シーンで自然に設定を説明できる
- **人間関係の構築**：同期の貴族子弟との友情・対立・政治的関係の芽生え
- **格差の体感**：学院内の上下関係を通じて、社会の構造を読者に見せる
- **辺境との対比**：学院での知識と、後に訪れる辺境・辺境学舎の現実との落差
