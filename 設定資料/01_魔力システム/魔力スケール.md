# 魔力スケール

## このファイルの目的

魔力量を**定量的に扱うための共通単位**を定義し、人間・魔物・魔法行為・大型魔道具の魔力消費を統一スケールで並べる。物語中で魔法・魔道具の規模感がぶれないようにするための参照表。

> 本ファイルは現状、**東の国（ルクスマーレ王国）の運用前提**で数値を組んでいる。他国（コンコルディア盟邦・ドミナトゥス帝国）の数値は別途検討する。

---

## 基本単位：MU（Magic Unit）

### 定義(物理準拠)

**1 MU ＝ 1 kJ（キロジュール）＝ 1000 J**

本単位は物理エネルギーと直接対応する。すべての魔法コストは [[物理コスト原理]] に従い、運動エネルギー (1/2)Mv²・熱エネルギー mcΔT・相転移 mL・位置エネルギー mgh・化学結合エネルギー・破壊仕事量の物理式から算出する。

> **旧定義（「6歳児火灯の術1回 = 1 MU」）からの改訂**
>
> 旧定義は直感的な基準値として機能してきたが、物理整合性のため新定義に移行した。
> 旧定義の「火灯の術1回」は新単位系では **0.01〜0.05 MU** 程度（薪・芯部の局所加熱分のみ）に相当する。魔力検査の段階表現は廃止せず、「段階4反応 ＝ 基礎的な火起こしが可能」という定性記述として維持する（→ [[魔力検査]]）。

### この単位の利点

- **物理エネルギーと直結**するため、熱・運動・化学結合が全て同じMU単位で計算できる
- 現実の物理定数（比熱・潜熱・燃焼熱）をそのまま使えるため世界内の「学問」として魔法が成立する
- 既存の総魔力量スケール（平民 3,000〜5,000 MU 等）は個別スペル消費の再計算によって維持される

## 人間の総魔力量

「総魔力量」は副魔石を含めた満タンの貯蔵量。**一晩の睡眠でほぼ満タンに回復する**ため、1日で総魔力量のほぼ全量を使い切っても健康上の問題はない（[[消費とコスト]]）。ただし職業として連日使う場合は体感疲労を避けるため低めに抑えるのが普通（下記「1日あたりの使用量の段階」参照）。

下表は**男女別に示す**。女性は副魔石の分で男性の約2倍の総魔力量を持つ（[[魔石の仕組み]]）。ただし副魔石は思春期以降に本格成長するため、**6歳時点では男女差はほぼない**。

| 区分 | 男性（MU） | 女性（MU） | 備考 |
|---|---|---|---|
| 無魔人（大人） | 20〜50 | 40〜100 | 副魔石なし。主魔石もないため男女差は微小 |
| 6歳児・魔石持ち（標準・段階4反応） | 100 | 100 | 単位定義の基準値。副魔石未成熟 |
| 6歳児・魔石持ち（強・段階6反応） | 1,000 | 1,000 | 6歳で大人下級貴族相当。副魔石未成熟 |
| 魔石持ち平民・大人（標準） | **2,000〜5,000** | **4,000〜10,000** | 国民の魔石持ちの中央値 |
| 中級騎士・下級貴族・大人 | 20,000〜50,000 | 40,000〜100,000 | C級魔物を捌けるライン |
| 上級騎士・上級貴族 | 200,000〜500,000 | 400,000〜1,000,000 | B級単独討伐ライン |
| 公爵・王族（高位） | 200万〜500万 | 400万〜1,000万 | A級討伐部隊の中核 |

> **レンジ幅の内訳**：各区分の幅（およそ2.5倍）は**個体差・年齢・鍛錬による**もの。女性上限は男性上限の約2倍（副魔石分）、下限も同様に2倍の関係。

### 成長倍率のルール

6歳児の検査値と大人の総魔力量の関係は、**検査段階に関わらず成人時点で約20〜50倍に成長する**という経験則がある（女性はさらに副魔石の本格成長で男性の約2倍に到達する）。

| 6歳の検査反応 | 6歳時点の魔力量 | 成人男性の標準範囲 | 倍率 |
|---|---|---|---|
| 段階4（平民魔石持ちの中央） | 100 MU | 2,000〜5,000 MU（平民・男） | ×20〜50 |
| 段階5 | 300 MU | 6,000〜15,000 MU | ×20〜50 |
| 段階6（下級貴族相当） | 1,000 MU | 20,000〜50,000 MU（中級騎士・男） | ×20〜50 |
| 段階7 | 3,000 MU | 60,000〜150,000 MU | ×20〜50 |
| 段階8（上級貴族相当） | 10,000 MU | 200,000〜500,000 MU（上級貴族・男） | ×20〜50 |
| 段階9以上 | 30,000 MU〜 | 数百万 MU（公爵・王族・男） | ×20〜50 |

> この「×20〜50倍則」は、副魔石・主魔石の成長が思春期以降に本格化するための物理的な結果。女性はさらに副魔石の本格成長で男性の2倍に到達する。

### 魔石容量 ≠ 戦闘力

人間の総魔力量や魔物の魔石貯蔵量は **「所有魔力の最大量」** であり、**戦闘力そのものではない**。実戦での勝敗は以下の要素の掛け算で決まる。

- **技能・訓練**：同じ魔力量でも発動の精度・速度・省エネ度で数倍の差が出る
- **武具・魔道具**：騎士の剣には強化・斬撃術式が刻まれ、魔力効率を数倍に高める
- **戦術・連携**：単独より連携、地形・奇襲・陽動の効果は大きい
- **魔物の身体能力**：A級魔物は魔力量だけでなく牙・爪・鱗・知性も持つ

したがって「**公爵級10人分の魔力＝A級1体**」は単純な魔力収支であり、「**公爵10人で必ずA級1体を倒せる**」ことは意味しない。逆に、**平民魔石持ち（数千MU）でも武具と連携があればD級魔物（3万MU）の討伐が可能**（魔力差10倍を武具・戦術で補う）。この「**魔力量以外の要素**」は他の設定資料で定義される。

### 1日あたりの使用量の段階

魔力は**一晩の睡眠で貯蔵量のほぼ全量が回復する**（[[消費とコスト]]）。したがって「1日で総魔力量の何%を使えるか」ではなく、「どの強度で使うと体にどんな負荷がかかるか」を段階で捉える。

| 使用ペース | 1日あたりの消費目安 | 体感・用途 |
|---|---|---|
| 日常労働（持続可能ペース） | 総魔力量の **5〜15%** | 疲労感なし。連日年単位で続けられる。術式石の充電業・生活魔法・家事 |
| 通常戦闘・集中訓練 | 総魔力量の **30〜60%** | 夜には疲労・頭痛が残るが睡眠で回復。騎士の日常任務・模擬戦 |
| 全力運用 | 総魔力量の **80〜100%** | 酷使の症状（頭痛・発熱）が出る。スタンピード防衛・緊急事態限定 |
| **枯渇後の酷使** | 100%を超えて絞り出す | **主魔石にひびが入る**（[[消費とコスト]]）。戦場の極限でのみ |

### 魔石への負荷

- **通常使用**：タンクの残量が減るだけで、魔石そのものには負担がない。一晩で回復
- **枯渇後の酷使**：男女共通で**主魔石にひびが入る**。安静で長期間かければ回復するが、完全破損は不可逆
- **副魔石（女性のみ）への意図的破損**：最重禁忌・戦争犯罪。出産時の子への魔力譲渡ができなくなる

### 「持続可能ペース」と充電労働

術式石の充電を職業として長年続けるには、日常労働の範囲（総魔力量の5〜15%）に抑えるのが標準。

| 階層 | 総魔力量（男/女） | 持続可能な1日の充電量（男/女） |
|---|---|---|
| 平民魔石持ち | 男 2,000〜5,000 / 女 4,000〜10,000 MU | 200〜750 / 400〜1,500 MU（F〜E級術式石1個相当） |
| 下級貴族・中級騎士 | 男 2万〜5万 / 女 4万〜10万 MU | 2,000〜7,500 / 4,000〜15,000 MU（D級術式石の一部） |
| 上級貴族 | 男 20万〜50万 / 女 40万〜100万 MU | 2万〜7.5万 / 4万〜10万 MU |

### 産業・生活

| 行為 | 物理根拠 | 消費 |
|---|---|---|
| 鍛冶場通風石（1日） | 通風持続 | 100〜500 MU |
| 村の浄化術式石（1日） | 分離操作 | 200〜1,000 MU |
| パン窯維持（200℃、1時間） | 空気 2 m³ ＋ 放熱補填 | 400〜800 MU |
| 鉄 1 kg を鍛造温度（1,200℃）まで加熱 | mcΔT（450×1×1180） | 530 MU |
| 鉄 1 kg を溶融（潜熱含む） | 顕熱 665 ＋ 潜熱 247 | 912 MU |
| 風呂沸（100 L を 20→40℃） | mcΔT | 8,370 MU |

**重要**：鍛造や溶融は物理的に大量の熱量を要する。平民単独では不可能で、上級職人（数万 MU保有）または燃料（薪・炭）の化学エネルギーを活用する必要がある。これが「火魔法使いが鍛冶を独占する」設定の物理的根拠となる。

## 既存設定との整合チェック

物理準拠化（1 MU = 1 kJ）後の整合性確認。

| 既存記述 | 物理準拠での再現 |
|---|---|
| 密着型魔防壁・中：1時間60〜100 | 矢50 J×十数回＋予備＝60〜100 kJ = 同値 ✓ |
| 魔石持ちは人口の5〜8% | 社会制度設定とは独立なので不変 ✓ |
| 大人下級貴族 = 中級騎士相当、20,000〜50,000 MU | 20〜50 MJ の総エネルギー。ライフル弾7,000〜16,000発相当 ✓ |
| 旧「火灯の術 = 1 MU」 | 物理準拠で 0.01〜0.05 MU（微小加熱）に改訂。魔力検査の「段階」は定性表現として維持 |

## 特殊系魔法使いのスケール外性

同調魔法使い・念写・念視・魔石記憶などの特殊系魔法使い（[[03_特殊魔法]] 各ファイル参照）は、**本スケール表の延長線上に位置づけられない**。

理由は以下のとおり。

- 通常の属性魔法（土・水・火・風）では測れない系統外の魔法であり、6歳検査での「段階」が付かない
- 魔力量そのものは通常の魔石持ちと同程度（平民〜貴族のどこにも出うる）だが、**魔法の効果が魔力量に比例しない**
- 同調魔法は「共鳴・響き合い」で成立するため、1対1の対象が関わる魔法は数十〜数百 MU で成立する一方、対象がいなければ0 MUでも成立しない
- 念視・念写は「成功率」と「情報量」が主要な変数で、MU値は参考程度

**主人公**はこの系統に属するため、物語上の扱いは**「通常スケールに乗らない特殊系」**とし、数値ではなく**質的な描写**で強さを示す（詳細は [[主人公魔法]] および [[13_キャラクター/主人公.md]] 参照）。

## 未設定・検討中

- [x] 魔泉接続による無料魔力供給の規模感 → **西の国コンコルディアの辺境都市で1日数十万 MU（中都市の大型術式石1個分を相殺可能）**。ただし魔泉からの距離に応じて急減衰し、東の国ルクスマーレは魔泉が遠いため接続の利点はほぼない（詳細は [[禁域設定]] [[魔泉の移動]] 側で扱う）
- [x] 副魔石を使い切ったときの女性の出産能力への影響 → **副魔石を枯渇状態のまま出産すると、子の主魔石が弱く（または未形成に）なる**。戦闘で副魔石をほぼ使い切った女性は数年の回復期間を経てから出産するのが慣習（詳細は [[医療と出産]] 側で扱う）。副魔石の**破損**（ひび以上）は不可逆で、以後の出産での魔力譲渡が不可能になる
- [x] 同調魔法使い（特殊系）の魔力スケールへの当てはめ方 → 本ファイル「特殊系魔法使いのスケール外性」で定性記述
- [x] 主人公アウレリアの魔力量設定 → 特殊系のため数値ではなく質的描写で扱う
