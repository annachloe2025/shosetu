# 髪色と魔力属性

## 概要

この世界では、人間の髪色は生まれ持った**魔力属性**を反映して変化する。
魔力属性は古代5系統の生物に由来する遺伝子が主魔石で発現したもので、**古代系統が持っていた環境色の色素遺伝子**と染色体上で近接している。そのため属性が発現すると対応する色が髪に現れる（進化的根拠は [[属性の遺伝起源]]）。

髪色を見ればその人の属性傾向と魔力の強さがおおよそ分かる。

---

## 4大属性と対応色

魔力には4つの根源的な属性がある。これは魔力そのものの「性質」であり、魔力の「使い方」であるカテゴリ（属性魔法・強化系・感知系）とは別の軸である。

| 属性 | 対応色 | イメージ |
|------|--------|----------|
| 火 | 赤（R） | 炎のような赤〜深紅 |
| 水 | 青（B） | 海や空のような青〜藍 |
| 土 | 黄（Y） | 大地のような黄〜琥珀 |
| 風 | 緑（G） | 森や風のような緑〜翠 |

### 属性と系統の関係

- **属性（火水土風）**：先天的。古代5系統の遺伝子発現。母親の副魔石が濃縮・保管した5系統遺伝情報が、出産時に子の主魔石の「種」に転写されて継承される。副魔石は女性のみが持つ生殖魔石であり、遺伝情報の濃縮と転写を担うが、**副魔石という器官そのものが子に引き継がれるわけではない**（[[魔石の仕組み]]・[[属性の遺伝起源]]）。
- **カテゴリ（属性魔法・強化系・感知系）**：後天的。魔力の運用技術。訓練で誰でも伸ばせる。

属性はカテゴリに影響しない。火属性だから属性魔法しか使えないということはなく、火属性で感知系が得意な者もいれば、水属性で強化系に秀でた者もいる。ただし、属性魔法においては自分の属性と一致する元素の操作効率が高くなる傾向がある（火属性の者が火を操る方がマーキングと共鳴しやすい、など。詳細は [[操作系魔法の統一原理]]）。

## 髪色の決まり方

### 加法混色モデル（RGBYモデル）

髪色は4属性の強度の組み合わせによって決まる。概念としてはRGBの加法混色に近い。

| 状態 | 属性強度 | 髪色 |
|------|----------|------|
| 魔力なし（無魔人・平民） | 全属性≒0 | **黒** |
| 単一属性・強 | 1属性が突出 | その属性の色（赤/青/黄/緑） |
| 2属性混合 | 2属性が強い | 混合色（下表参照） |
| 全属性・高 | 全属性が高い | **白**に近づく |
| 同調魔法使い | 5系統均衡発現（群体含む） | **白**（銀白色）／※「全属性高」の極限例。群体系統の発現も加わり銀白色になる |

### 2属性の混合色の例

| 組み合わせ | 混合色 | 備考 |
|-----------|--------|------|
| 火＋水 | 紫（パープル） | 赤と青の混合 |
| 火＋土 | 橙（オレンジ） | 赤と黄の混合 |
| 火＋風 | 茶褐色〜暗赤色 | 赤と緑の混合 |
| 水＋土 | 黄緑〜浅葱色 | 青と黄の混合 |
| 水＋風 | 水色〜碧（シアン） | 青と緑の混合 |
| 土＋風 | 黄緑〜萌黄色 | 黄と緑の混合 |

### 魔力量と色の濃さ

髪色の**色相**は属性の種類で決まり、**彩度・明度**は魔力量で決まる。

- **魔力が低い**：色が暗く沈む → 黒に近い（属性があっても分かりにくい）
- **魔力が中程度**：属性の色がはっきり見える
- **魔力が高い**：色が鮮やかになる
- **魔力が極めて高い**：色が明るく輝くような印象を受ける

> つまり、平民（無魔人）の黒髪は「属性がない」のではなく「主魔石がなく属性遺伝子が発現しないため色素も現れない」状態。無魔人も属性遺伝子自体は持っているが（祖先が魔石持ちであったため、[[人間の魔力量]]）、発現器官である主魔石を欠いているため外見に出ない。

## 髪色の発現タイミング

髪色は成長とともに徐々に変化する。属性継承の二段階プロセスを反映し、色の変遷が起こる。

| 時期 | 髪色の状態 | 属性の状態 |
|------|-----------|-----------|
| 誕生時 | ほぼ全員が黒〜暗色 | 副魔石由来の初期属性。まだ発色しない |
| 乳幼児期（0〜3歳） | うっすらと色味が出始める | 初期属性（副魔石由来）の色が薄く現れる |
| 幼少期（3〜7歳） | 色が変化し始める | 主魔石回路の属性が目覚め始め、初期属性から遷移が始まる |
| 成長期（7〜15歳） | 色が安定に向かう | 訓練により主属性が確立。名家の子は家の色に染まる |
| 成人以降 | 基本的に安定 | 魔力量の変動（出産・魔石損傷）で微変化する程度 |

> **観察ポイント**：名家の子は幼少期に「最初は別の色だったのが、家の色に変わっていく」様子が見られる。これは副魔石由来の初期属性から主魔石回路の属性へと遷移する過程である。一般にはこの変化を「家の血が目覚める」と表現する。

### 出産と髪色

女性は出産を重ねるごとに主魔石が成長し魔力が安定増加するため、経産婦の髪色がより鮮やかになることがある。逆に、副魔石が損傷を受けた場合は色がくすむ。

---

## 属性の継承メカニズム

属性の継承は二段階のプロセスで行われる。出産時に母親の副魔石が濃縮した**5系統遺伝情報**を子の主魔石の「種」に転写し、その後成長過程で母親の主魔石由来の回路が属性発現を書き換えていく。

副魔石は古代5系統（地中・水棲・火山・空中・群体）の遺伝情報を濃縮保管する女性専用器官であり、出産時にこの情報を子の主魔石の種に「書き込む」役割を担う。**副魔石という器官そのものは母親の体内に留まり、子に渡るのは情報のみ**（[[魔石の仕組み]]・[[属性の遺伝起源]]）。

### 第1段階：誕生時の初期属性（副魔石由来の情報）

子は母親の副魔石から転写された**5系統遺伝情報**を主魔石の種として受け取って生まれる。この時点で遺伝情報の中に「どの系統を優勢発現させるか」という初期パターンが刻まれており、これが**誕生時の初期属性**となる。

初期属性は母親の副魔石内で濃縮された5系統のうち、どの系統が卓越していたかで決まる。母親自身の主属性に近い場合もあれば、祖先世代の情報が強く出て母と異なる属性になる場合もある。

ただし、この時点で受け継いだ主魔石には、母親の**主魔石から転写された魔力回路**も刻まれている。回路には属性発現の偏向情報と、母親が習得してきた属性魔法・無属性魔法（強化系・感知系）の運用パターンの両方が含まれる。

### 第2段階：成長による属性の変遷（主魔石回路の影響）

子が成長し、魔力を使い始めると、主魔石に刻まれた母の主魔石由来の回路に魔力が流れ始める。これにより、**初期属性（副魔石の情報由来）から、母の主属性（主魔石回路由来）へと属性発現が徐々に移行していく**。

この変遷は自然にも起こるが、意図的な訓練によって大きく加速される。貴族家系では家の属性を維持するために、幼少期から特定属性の訓練を行う。

### 具体例：火属性の公爵家の場合

```
【母親】
  主魔石：火属性（強い）
  副魔石：5系統遺伝情報を濃縮（母自身が祖母から継承した情報＋父から精子経由で得た情報の統合）
         この家系では火系統と土系統が特に濃縮されている

【誕生した子】
  主魔石の種 ← 母の副魔石から5系統情報を転写（火と土が優勢、初期は土が卓越）
  主魔石の回路 ← 母の主魔石から転写（火属性の回路＋母が習得した各種魔法の回路）

【誕生直後】
  → 初期属性は「土」。髪色はまだほぼ黒（魔力が弱く発色しない）

【乳幼児期（0〜3歳）】
  → うっすらと黄色みが出始める（土属性の発色）

【幼少期（3〜7歳）：火属性の訓練開始】
  → 主魔石に刻まれた火の回路に魔力が流れ始める
  → 火属性が強まり、髪色が黄色→橙→赤みへと変化
  → 土属性は弱まるが完全には消えない（5系統情報は保持される）

【成長期〜成人】
  → 火属性が主属性として確立。髪色は赤（公爵家の象徴色）
  → 土属性は副属性として残り、土の属性魔法もある程度使える
  → 母から継承した属性魔法・無属性魔法（強化系・感知系）の回路も活用でき、母が得意だった魔法は覚えやすい

【女子の場合：10歳前後】
  → 主魔石に保持された5系統情報の濃縮器官として、自前の副魔石が新規に形成される
  → 母の副魔石を引き継ぐのではなく、主魔石が持つ情報を基に自分の副魔石を構築する
```

### 原理のまとめ

| 要素 | 由来 | 影響 |
|------|------|------|
| 初期属性 | 母の副魔石が転写した5系統情報 | 誕生時の属性。副属性として残る |
| 継承回路の属性 | 母の主魔石 | 成長とともに主属性発現を書き換えていく |
| 継承回路の系統 | 母の主魔石 | 母が得意だった系統の習得が速くなる |
| 最終的な主属性 | 訓練＋継承回路 | 回路に沿った訓練をすれば母の主属性と同じになる |
| 副属性 | 初期属性（5系統情報）の残存 | 完全には消えず、ある程度の適性が残る |
| 娘の副魔石 | 主魔石の情報を基に10歳前後で新規形成 | 母の副魔石を物体として受け継ぐわけではない |

### 父親の属性の影響

父親の属性は、**精子が運ぶ5系統遺伝子として母親の副魔石に届き、副魔石で濃縮される過程で子に反映される**。したがって父親の影響は完全に排除されるわけではなく、副魔石の濃縮内容に混じる形で継承される。

- 父の系統情報は母の副魔石で他系統と統合され、子の主魔石の種に書き込まれる
- その結果、子の初期属性は「母の主属性に近い」のが基本だが、父の強い系統が隔世的に顔を出すケースもある
- 長年同じ属性同士の婚姻を繰り返す家系では、副魔石の濃縮が単一系統に偏っていく

### 名家の属性維持戦略

貴族の名家は何世代にもわたって同じ属性を維持するために、以下の戦略を取っている。

- **婚姻政策**：同じ属性の家系から嫁・婿を迎えることで、副魔石に濃縮される5系統情報を家の属性に偏らせる
- **幼少期からの訓練**：母の主魔石由来の回路を早期に活性化させる
- **世代蓄積**：何世代も同じ属性の回路を蓄積することで、継承される回路がより深く強くなる
- **副作用**：同属性婚を重ねすぎると群体系統が希薄化し、同調魔法の発現確率が家系的に下がる（[[四大公爵家]] 参照）

→ これが「鮮やかな単一色の髪＝名家の証」という社会的認識の根拠

### 隔世遺伝

継承される回路にはランダム性がある。通常は母の主属性の回路が優先されるが、稀に遠い祖先の属性回路が突然強く転写されることがある。例えば、代々火属性（赤髪）の家系から突然水属性（青髪）の子が生まれるなど。

これは家系にとって「血の乱れ」と見なされることもあれば、「先祖返りの才能」として重宝されることもあり、家の方針や文化によって受け止め方が異なる。

## 特殊な髪色

### 同調魔法と白髪

同調魔法の適性者は、古代群体系統の遺伝子が発現した個体である（[[属性の遺伝起源]]）。群体系統は遺伝子プールへの寄与が小さかったため、現代では稀にしか発現しない。発現には5系統の遺伝子がほぼ均等に継承されている必要があり、結果として4属性への親和性も均等に近くなる。

視覚的にはRGBの加法混色において全チャンネルが最大値に近づく状態となり、髪色は**白〜銀白色**になる。

- 同調魔法の発現は群体系統遺伝子のランダム性が大きく、黒髪の平民（無魔人）から白髪の子が生まれる可能性もゼロではない（極めて稀。祖先の遺伝子が突然強く発現する例）
- 白髪は「聖女の印」として宗教的に神聖視されている
- 東の国では白髪の出現を「聖女の血の証」と信じているが、これは王室と教会が作り上げた誤解

### 主人公（アウレリア）の髪色

アウレリアは同調魔法の適性者であり、かつ母セレストリアから強い魔力を受け継いでいるため、成長とともに髪色が**黒→銀→白**へと変化していく。

- 誕生時は暗い色
- 乳幼児期に銀がかった色味が出始める
- 幼少期には明らかな銀白色に
- これが周囲に「聖女の再来」として注目される契機となる

## 社会的意味

### 髪色は身分の指標

髪色を見れば、相手が魔石持ちかどうか、どの属性か、どの程度の魔力を持っているかがおおよそ判別できる。これは以下の社会的影響を持つ。

- **貴族の識別**：鮮やかな髪色は高い魔力と属性の証。名家ほど色が鮮やかで統一されている
- **平民との視覚的区別**：黒髪＝平民・無魔人という認識が広く浸透している
- **差別の助長**：髪色が身分の可視化となり、社会的差別を固定化する一因
- **偽装の困難さ**：髪色は古代系統の色素遺伝子が属性遺伝子と連動して発現したもので、染めても根本は変わらない。魔力による発色は染料より深層にあり、表面的な染色ではすぐに元の色が透ける

### 貴族家系と髪色のブランド

有力な貴族家系は、何世代にもわたって特定属性を重視した婚姻政策を行ってきた結果、家系ごとに特徴的な髪色を持つ。これが家名と結びつき、一種のブランドとなっている。

例：
- 火属性を重んじる公爵家 → 鮮やかな赤髪が家系の象徴
- 水属性の伯爵家 → 深い青髪
- 複数属性を持つ辺境伯家 → 独特の混合色

---

## 多種族への適用

この髪色と属性の仕組みは**全ての種族に共通して適用される**。魔石を持つ知性体であれば、人間・エルフ・獣人・その他の種族を問わず同じ原理で髪色が決まる。

### 種族ごとの特徴

| 種族 | 髪色の傾向 | 備考 |
|------|-----------|------|
| 人間（現代人類種） | 属性により多様 | 魔力量による濃淡差が大きい。平民は黒髪が圧倒的多数 |
| エルフ（古代人種） | 非常に鮮やか | 長寿で魔力が高いため発色が強い。単一属性が多く、深い色になりやすい |
| 獣人（現代亜人種） | 体毛にも属性色が現れる | 毛皮の色にも微かに属性が反映される場合がある |
| 古代亜人種 | 種による | ゴブリンやオークなどは肌色への影響が強い個体もいる |

### エルフの髪色

エルフは数百〜千年以上の寿命を持ち、魔力量も高いため、髪色は非常に鮮やかで深みのある色になる。人間の貴族でも到達しないほどの色の純度を持つことがあり、エルフの美しい髪色は物語世界で広く知られている。

---

## 瞳の色について

髪色ほど顕著ではないが、瞳の色にも属性が微かに影響する場合がある。ただし、髪色ほどの法則性はなく、個体差が大きい。物語上は髪色を主要な識別手段とする。

## 補足：4大属性とカテゴリの関係図

```
┌─────────────────────────────────────┐
│           魔力の2つの軸              │
│                                     │
│  【属性】先天的・髪色に影響         │
│   火(R) ─ 水(B) ─ 土(Y) ─ 風(G)   │
│   → 魔力そのものの性質             │
│   → 母副魔石の5系統情報を継承      │
│                                     │
│  【カテゴリ】後天的・髪色に影響しない │
│   属性魔法 ─ 強化系 ─ 感知系       │
│   → 魔力の運用方法                 │
│   → 訓練で伸ばせる                 │
│                                     │
│  ※ 属性×カテゴリ の組み合わせが    │
│    その人の魔法特性を決める         │
└─────────────────────────────────────┘
```
