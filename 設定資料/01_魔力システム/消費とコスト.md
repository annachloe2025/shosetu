# 魔力の消費とコスト

## 消費の仕組み（物理的実体）

魔力の実体は**魔力分子**（[[魔力分子とマーキング]]）という原子〜小分子スケールの粒子である。消費とは、魔石が自分用にマーキングした魔力分子の**運動・相転移・結合変化エネルギーが物理的な仕事として世界に吐き出される**ことで、マーキング状態が外れて大気に戻る過程である。

魔力を使うと「魔石タンク内の魔力の消耗」と「体への負荷」の両方が発生する。
消費された魔力は消滅せず、**マーキングが外れた魔力分子として大気中に拡散**する。マーキングは数時間以内に自然減衰して天然魔力分子に復帰し、惑星規模の循環サイクルに戻る（詳細 [[魔力循環]]）。

> **物理整合性：**
> コスト計算は [[物理コスト原理]] に従う。1 MU = 1 kJ を基準単位とし、すべての魔法は以下の組合せで評価される。
> - 運動エネルギー (1/2)Mv²
> - 熱エネルギー mcΔT
> - 相転移エネルギー mL
> - 位置エネルギー mgh
> - 化学結合エネルギー（燃焼・分解）
> - 破壊仕事量
>
> 加えて、**馴染ませコスト**（対象結合エネルギーの数%）と**制御魔力**（精度・指向性・同時制御の情報コスト）が加算される。

## 魔力分子モデル

魔力は「マーキング → 消費 → マーキング消失」という不可逆過程を経る（[[魔力分子とマーキング]]）。

```
天然の魔力分子（大気・水・土壌中）
　↓ 呼吸・飲食で体内に取り込まれる
　↓ 主魔石でマーキング（自分用魔力分子になる）
自分用魔力分子（魔石タンク＋体内分布）
　↓ 魔法発動で物理エネルギーに変換
物理エネルギー（熱・運動・化学結合変化）として世界に作用
　↓ 仕事を終えた魔力分子はマーキングが減衰
天然の魔力分子に復帰（数時間オーダー）
　↓ 大気中に拡散
【魔力循環の経路】上昇気流 → 赤道方向 → 下降・凝縮
　↓
赤道生態系・地中を経由して再び天然魔力分子として循環に復帰
```

### 魔力分子の物理的特徴

- **原子〜小分子スケール**：通常の化学計測では検出困難。感知系魔力使いは他者のマーキング紋様として間接的に感じ取るのみ
- **惑星規模で保存**：宇宙空間への散逸はほぼ無視できる
- **再構成不要**：消費された魔力分子も分子そのものは壊れない。マーキングが外れるだけで、循環を通じて再びマーキング対象になる
- **物語的扱い**：裏設定として整合性のためのみ設定。本文描写には通常出さない

### 魔力消費の「向き」

| 過程 | 方向 | 備考 |
|------|------|------|
| 魔石内魔力 → 魔法発動 | 自分用魔力分子 → 物理エネルギー ＋ マーキング減衰 | 通常の消費 |
| 食事 → 魔力補充 | 食物中の魔力分子 → 主魔石で再マーキング | 呼吸でも同じ経路 |
| 魔石内魔力 → 魔石劣化 | 魔力 → 魔石構造への応力 | 枯渇状態での酷使時 |

## 消費の構成要素（詳細）

### 通常使用
- 魔石（タンク）から魔力が消費される
- 休息・睡眠・食事で自然回復する（一晩でほぼ全回復）

### 酷使・連続使用
- 魔力の流れが体に負荷をかける
- 疲労・頭痛・発熱として現れる

### 魔力枯渇
- タンク内の魔力がゼロになると魔法が発動できなくなる
- この状態で魔力の充填（休息・食事・ポーション等）が必要

### 枯渇状態での酷使
- 魔力ゼロの状態でさらに魔法を使おうとすると、魔石そのものに負荷がかかる
- 魔石にひびが入り始める
- 最終的に魔石が破損すると集中的な魔力運用を失う（体組織全体の微弱な残存マーキングは残り、生命は維持できる）

## 女性の有利な点

魔力量が多い女性は：
1. 「タンクが大きい」＝同じ使用量でも消耗比率が小さい
2. 「体への負荷も分散できる」＝酷使しても倒れにくい
3. 枯渇状態に陥りにくい＝魔石破損のリスクが低い

→ 魔力量の差が戦闘持続力の差にも直結する。

---

## 魔石損傷のリスク

| 状態 | 症状 |
|------|------|
| 軽度酷使 | 疲労・頭痛・発熱 |
| 重度酷使 | 魔石にひびが入る（回復に長期間必要） |
| 魔力枯渇 | 魔法が使えなくなる。充填が必要 |
| 枯渇状態で酷使 | 魔石破損→集中的な魔力運用を失う（微弱な残存マーキング能力は保持） |

魔石のひびは安静と時間で回復できるが、完全破損は不可逆。破損後は主魔石による集中的な魔力運用はできなくなるが、体組織全体で天然魔力分子を弱くマーキングする残存能力は維持されるため生命活動は継続する（[[人間の魔力量]] 参照）。

---

## 魔力の回復方法

| 方法 | 回復速度 | 備考 |
|------|---------|------|
| 睡眠 | 一晩でほぼ全回復 | 最も基本的な回復手段 |
| 食事 | 緩やか | 死んだ生物の魔力を摂取（食料の基礎原理） |
| ポーション | 即効性あり | 薬草由来の魔力を濃縮したもの |
| 魔石の摂取 | 非常に速い | 魔物が行う方法。人間は通常行わない |
