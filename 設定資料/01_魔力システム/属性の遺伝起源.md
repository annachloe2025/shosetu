# 属性の遺伝起源

## 核心仮説

現代の魔石持ちが持つ4大属性（火・水・土・風）と、同調魔法のような稀な能力は、
**遠い過去に環境特化して進化した古代生物の遺伝子が、交配と長い年月を経て現代種の遺伝子プールに組み込まれたもの**である。

属性とは「物理現象への干渉ルート」そのものではなく、**「どの古代系統の遺伝子を優勢に発現したか」**で決まる。これが髪色・魔石色・魔法の得手不得手のすべての根拠になる。

> **重要な語彙整理**：「同調属性」という用語は廃止。同調魔法は属性ではなく、**古代5系統（特に群体系統）の遺伝子が均衡して濃く発現した稀な主魔石構造が持つ能力**である。旧表現（同調属性／同調属性の副魔石など）は全廃。

---

## 古代5系統の生物

惑星誕生後、最初の知性なし原初生物の時代（[[6つの時代]] 第一期）から、環境特化型の生物が各地で進化した。その中で特に魔力への強い親和性を獲得した5つの系統がある。

| 古代系統 | 生息環境 | 獲得した能力 | 現代の対応 |
|---------|--------|------------|-------------|
| **地中系統** | 地下・岩盤・洞窟 | 岩石・鉱物の結合に干渉 | **土属性** |
| **水棲系統** | 深海・河川・氷海 | 流体・水分子結合・相転移に干渉 | **水属性** |
| **火山系統** | 火口周辺・熱源地帯 | 熱・燃焼・分子励起に干渉 | **火属性** |
| **空中系統** | 高層大気・風帯 | 気流・気圧・自由気体に干渉 | **風属性** |
| **群体系統** | 広域分布・個体数少 | 他個体の魔力と共鳴・通信 | **同調魔法の基盤**（属性ではなく能力） |

これらの古代系統は、それぞれの環境下で**魔力分子を特定の物理パターンと結びつけて扱う器官（原始魔石）**を発達させていた。この器官の進化的起源が現代の「主魔石」である。

## 陸上への進出と交配

ある時代（[[6つの時代]] 第一期後半〜第二期前）、惑星の環境変動（氷期・地殻変動・魔泉噴出の変動など）により、これらの古代系統が**陸上の緩衝地帯に集まり、長期間にわたって交配可能な状態**が続いた。

- 元々の生息環境が失われた系統も、陸上で新環境に適応した
- 交配は最初は稀だったが、魔力分子による共鳴で世代を重ねるごとに成功率が上がった
- 結果として、現代種の祖先の遺伝子プールに**5系統すべての遺伝情報（うち4系統が属性として、群体系統は同調魔法の基盤として）**が取り込まれた

### 群体系統（同調の基盤）が少数派になった理由

群体系統は元々個体数が少なく、また繁殖戦略上（群体単位の繁殖）で個体単独の子孫を残しにくかったため、遺伝子プールへの寄与が小さかった。その結果、現代では**群体系統の遺伝子を他4系統と均衡して濃く発現する個体（＝同調魔法使い）は非常に稀**となった（世界全体で同世代に2〜5人程度）。

## 遺伝モデル：属性の発現

### 基本構造

すべての現代種（人間・亜人・エルフ等）の遺伝子には、5系統すべての遺伝情報（4系統の属性遺伝子＋群体系統＝同調魔法の基盤）が組み込まれている。
どの属性が発現するかは、メンデル遺伝的な優性・劣性と、以下の要因で決まる。

- **両親の属性（髪色）の組み合わせ**
- **世代をまたいだ回路継承**（[[魔力回路と適性継承]]）
- **環境・訓練による後天的強化**

### 単属性と複属性

現代では、一個体に発現する属性は通常1〜2種類に絞られる。理由は：

- 5系統全ての遺伝子が均等に強く発現すると、魔石構造が安定しない
- 進化の過程で「発現を絞る」機構が選択された（器官の負荷軽減）
- 稀に3属性以上を発現する個体も存在するが、魔力制御が困難で短命な例が多い

### 複属性の例

- **火＋土**：火山系統と地中系統の両遺伝子が優勢発現。溶岩魔法など特殊用途
- **水＋風**：水棲系統と空中系統の混合。霧・嵐・氷雨などの現象に強い
- **火＋水**：火山系統と水棲系統。極めて稀。蒸気・温泉・雷（水と熱励起の複合）
- **3属性以上**：理論上存在可能だが、現代ではほぼ見られない

### 派生属性の可能性

古代5系統の範囲外でも、以下のような変異的発現が稀に観測される：

| 現象 | 説明 |
|------|------|
| **雷属性** | 火山系統の一部亜系統（落雷地帯に適応した変異）の遺伝子が稀に強く発現 |
| **氷属性** | 水棲系統のうち極地系統が単独で優勢発現した場合 |
| **光・闇** | 現代での発現は記録にほぼない。古代神話に断片的な記述があるのみ |
| **毒・治癒** | 系統横断的な発現。属性軸とは別の「有機魔法」側で扱う（[[4系統と適性]]）|

**これらは「古代5系統から派生した遺伝的変異」として、後から拡張が効く構造になっている。**

## 副魔石と属性遺伝

### 副魔石＝5系統遺伝情報を濃縮する女性専用器官

女性のみが持つ副魔石（[[魔石の仕組み]]）は、進化的には**古代5系統（地中・水棲・火山・空中・群体）の遺伝情報を濃縮し、出産時に子の主魔石の「種」に転写するために特化した生殖器官**である。

- **主魔石**：全個体が持つ。マーキング・魔力貯蔵・自己の魔法発動を担う。属性遺伝子の発現の場でもある
- **副魔石**：女性のみ。古代5系統の遺伝情報（両親から受け継いだぶん）を濃縮して保管する。出産時に情報を子の主魔石の「種」に転写する

> **重要**：副魔石という器官そのものが子に引き継がれるわけではない。子の体内で形成されるのは主魔石であり、女性の場合は成長過程（10歳前後〜）で自前の副魔石を新たに形成する。転写されるのは「5系統遺伝情報」であって、物体としての副魔石ではない。

### 男性の属性発現と伝達

男性は副魔石を持たないが、**主魔石に属性遺伝子の発現パターンが刻まれている**。

- 男性の属性は、母の副魔石から転写された5系統情報が、自身の主魔石で特定系統（優勢発現）として現れたもの
- 男性から子への属性伝達は、精子が運ぶ遺伝子として**配偶者（女性）の副魔石に届く**。女性の副魔石は父母両方の遺伝子を濃縮し、次世代に転写する
- つまり父親の属性遺伝子は「妻の副魔石経由で孫世代以降に届く」経路を取る

### 継承の経路整理

```
【父親（男性）】                【母親（女性）】
　主魔石：属性を発現・運用       主魔石：属性を発現・運用
　精子に5系統遺伝子を載せる       副魔石：両親の5系統遺伝情報を濃縮保管
                     ↓ 受精・妊娠
　　　　　　　　　　【子（男女）】
　　　　　　　主魔石の「種」 ← 母の副魔石から5系統情報が転写
                     ↓ 成長
           子が女性：10歳前後で自前の副魔石を形成（母の副魔石を継承するのではない）
           子が男性：副魔石は形成されない。属性は主魔石で発現のみ
```

## 属性と髪色の対応

古代5系統はそれぞれ環境色に応じた体色を持っていた（擬態・保護色の名残）。この色素遺伝子は属性遺伝子と染色体上で近接しているため、**属性が発現すると髪色にも同じ色が現れる**。

| 古代系統 | 環境色 | 現代の髪色 |
|---------|--------|----------|
| 火山系統 | 溶岩の赤〜朱 | 赤 |
| 水棲系統 | 深海の青 | 青 |
| 地中系統 | 土壌・鉱物の黄〜琥珀 | 黄 |
| 空中系統 | 森冠・雲陰の緑〜翠 | 緑 |
| 群体系統 | 群体発光の白〜銀 | 白（同調） |

詳細は [[髪色と魔力属性]] を参照。

## 魔石色との対応

死後採取した魔石の色が属性ごとに異なるのも、この遺伝モデルで説明できる。
主魔石の結晶構造は、発現している属性遺伝子が規定する。

- 火属性遺伝子が優勢発現している魔石：赤い結晶構造
- 水属性遺伝子が優勢発現している魔石：青い結晶構造
- （参考・属性ではない特殊例）同調魔法使いの主魔石：5系統均衡発現により透明〜白色

この結晶構造が、**術式石として使える魔法の属性**を制限する（[[魔石の仕組み]]「魔石の色と属性」参照）。

## 同調魔法の特殊性

同調魔法は古代群体系統の遺伝子発現に基づく能力であり、他の4属性とは質的に異なる。**「同調属性」という属性区分は存在せず、4大属性と並立する軸ではない**。

### 物理干渉ではなく他個体魔力への干渉

他の4属性が「物理現象のカテゴリ」に対応するのに対し、同調魔法は「他個体のマーキング済み魔力分子との共鳴」に対応する。
この軸の違いが、同調魔法が特異に見える理由。

### 発現条件

- 遺伝的には**5系統すべて（特に群体系統）を均衡して濃く継承している**ことが必要条件（群体系統が単独では弱いため、他4系統と協調して発現する必要がある）
- 結果として髪色は全属性の混合＝白となる（[[髪色と魔力属性]]）
- 群体系統遺伝子は特定家系に濃縮されていないため、血統からの予測は困難。世界全体で同世代に2〜5人程度という希少さ
- 男女どちらにも発現する（主魔石由来の能力のため性別中立）。同調魔法の発現条件は「子の主魔石が5系統均衡濃く発現する構造を持って生まれるか」であり、子の性別には依存しない（母が女性である限り副魔石経由での濃縮過程は必ず起こるため、発現者側の性別差はほぼない）

### 同調魔法でできること

- 他者の主魔石に魔力を送り込む（他者の充電）
- 念写・念視（他者のマーキング済み魔力分子を介した情報伝達）
- 複数人の魔法共鳴・集団魔法の主導

詳細は [[同調魔法]] を参照。

## 無魔人と属性

無魔人は主魔石を持たないため、属性遺伝子があっても発現の場がない。
（厳密には体組織全体で微弱なマーキングは可能だが、属性が乗るほどの集中器官がない。[[魔力分子とマーキング]]「無魔人とマーキング」参照）

- 両親のどちらかが無魔人でも、子に魔石があれば属性は発現する
- 無魔人×無魔人から稀に魔石持ちが生まれる（1%未満）場合、属性は祖先の遺伝子が現れる

## 既存設定との整合

| 既存設定 | 遺伝起源モデルでの説明 |
|---------|-------------------|
| 属性は母親の副魔石経由で継承 | 副魔石が5系統遺伝情報の濃縮器官。出産時に子の主魔石の「種」へ情報転写（副魔石自体は渡らない） |
| 4大属性（火水土風）が基本 | 古代4系統（地中・水棲・火山・空中）の遺伝子対応 |
| 同調魔法は希少 | 古代群体系統の遺伝子プール寄与が小さかった |
| 2属性持ちの存在 | 2系統の遺伝子が共に優勢発現 |
| 隔世遺伝が起こる | 世代間で発現が薄まりつつ受け継がれた遺伝子が、特定世代で強く現れる |
| 髪色と属性の対応 | 古代系統の環境色遺伝子が属性遺伝子と染色体上で近接 |
| 無魔人の存在 | 主魔石遺伝子の非発現個体（主魔石形成能力の喪失。体組織全体の弱いマーキングは残存） |
| 魔石の色が属性で変わる | 主魔石の結晶構造を属性遺伝子が規定 |
| 有機魔法は副魔石由来ではない | 有機魔法は属性軸と別系統（魔力回路の遺伝） |

## 世界観上の含意

### なぜ4属性なのか、に答えが出る

「属性が4つ（＋同調）なのは偶然ではなく、古代に5つの環境特化系統が存在し、そのうち4つが陸上で優勢交配したから」という進化史的必然として説明できる。

### 地域差・種族差が説明できる

古代系統の生息域と現代種の地理的分布が対応する：

- 山岳地帯の民に土属性が多い ← 地中系統の遺伝子が濃く残った地域
- 沿岸・島嶼の民に水属性が多い ← 水棲系統が陸上進出した地点
- エルフが風属性が多い ← 空中系統の高地適応版の子孫
- 火山地帯の民に火属性が多い ← 火山系統の直接子孫

### 新属性の追加が容易

後から物語上で「雷の魔石」「氷の魔石」「土と火の複属性」を出したい場合、
「古代には〇〇に住む亜系統もいた」「2系統の遺伝子が揃って発現した」と言えば済む。
物理法則を追加する必要がない。

### 古竜との関係

古代竜は第二期に知性を獲得した存在（[[6つの時代]]）。
古代5系統の進化的頂点に位置する個体群であり、5系統すべての属性を自在に扱える（現代種は発現が絞られたが、古代竜は古代から単一個体で全属性を保有する）。
これが「古竜は強大」の進化史的根拠となる。
