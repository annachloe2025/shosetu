# 古代竜設定

## 赤道生態系：大魔力生物の世界

### 赤道帯とは

魔力循環の設定では「赤道帯は魔力が極度に凝縮される」と定められている。
この環境は**生命の弱肉強食が何万年も続いた究極の戦場**である。

魔物は生まれ、戦い、死に、その魔力が惑星へ還元される。
死んだ者の魔力が生きている者を強くし、より強い者がその魔力を吸収する。
このサイクルが繰り返された結果、赤道帯の生物は**想像を絶する魔力量**を持つに至った。

> 赤道帯の魔物と、人類居住域の魔物は「魔物」という言葉を共有しているだけで、
> 実態はまったく異なる生物と見なしてよい。

---

## 大魔力生物の根本的制約：魔力依存

### 「強さ」の代償

赤道帯の頂点に立つ生物が持つ莫大な魔力は、同時に**致命的な制約**となる。

体内の膨大な魔力は常時消費することで安定を保っている。
この消費を補うためには、周囲に同等以上の魔力濃度がなければならない。

```
人間が酸素なしで生きられないように
大魔力生物は高濃度の魔力環境なしでは生きられない
```

| 魔力量 | 生存できる最低魔力濃度 | 行動可能範囲 |
|--------|---------------------|------------|
| 人間レベル | ほぼゼロでも生存可能 | 惑星全域（魔泉の核心部を除く） |
| 強力な魔物 | 緩衝地帯相当 | 禁域〜緩衝地帯 |
| 上位の古代生物 | 魔脈ベルト相当 | 禁域内のみ |
| 赤道の頂点種 | 赤道帯レベル | 赤道帯からほぼ出られない |
| **古代竜クラス** | **魔泉核心部レベル** | **魔泉の近傍のみ** |

**→ 強くなればなるほど、住める場所が狭くなる。これが大魔力生物の根本的な逆説である。**

---

## 危険度の階層：赤道帯の位置づけ

赤道帯を最上位とした、魔力濃度と危険度の連続的なグラデーション。

| 区分 | 魔力濃度 | 備考 |
|------|---------|------|
| **赤道帯** | **極限** | **古代竜でも自力では戻れない。頂点種の戦場** |
| 魔泉核心部 | 極大 | 古代竜が縄張りとする。人類到達不可能 |
| 魔脈ベルト（高濃度帯） | 高 | 赤道から逃れた強力な魔物が常住 |
| 緩衝地帯 | 中 | 冒険者の限界線 |
| 人類居住域 | 低 | 惑星全体の数%。魔物がほぼ出現しない |

## 北東の古竜（友好的古竜）

### 名前：ヴァルナディア（Varnadier）

古語で「静かなる循環」を意味する。var（巡る）＋ nadi（流れ）＋ er（者）。
人族が竜神殿を通じてこの名を知ったとき、「流れそのもの」という印象を抱いたと伝えられる。

### 外見：「枯れた白銀」

| 項目 | 内容 |
|------|------|
| 体長 | 翼を含めて数十メートル級。人類にとって圧倒的な存在感 |
| 体色 | **白銀〜灰白色**。全属性が極限まで高い存在（＝白に近づく）の体現。ただし輝きは失われ、白髪のような枯れた白 |
| 鱗 | 薄く、半透明に近い部分がある。光が当たると内部に淡い虹色の光沢が走る |
| 角 | 頭部から5本の角が王冠のように生え、先端が透き通っている |
| 瞳 | **虹彩が薄い金色**。深い知性と無関心が同居した目 |
| 翼 | 折り畳まれたまま。広げれば空を覆う大きさだが、本人に広げる意志がない |
| 全体の印象 | 雪山の頂にいる精霊のような存在。神々しいが、どこか寂しい。動かずにいると風景の一部に溶け込む |

> **外見の設計意図：** 全属性が極限に達した存在＝白（髪色設定と同じ原理）。
> しかし全盛期の輝きは失われ、魔泉の弱体化とともに「枯れた白」へと変わっている。
> 達観と無執着の哲学が、外見にも「静かに消えゆく美しさ」として現れている。

### 歴史：スタンピードの放逐体として生き延びた偶然

遠い過去、この古竜は**赤道帯の生態系において頂点に君臨していた**。
数万年にわたる赤道の弱肉強食を生き抜き、最強の座を得た存在である。

あるとき、唯一自分を脅かしうる存在との戦いに敗れ、赤道帯の外へ弾き出された。
これはスタンピードの発生メカニズムと同じ構造であり、本来ならば北へ進むほど魔力が尽きて消滅する運命だった。

> **注：** この出来事は人類が世界に誕生するよりはるか以前のことである。
> 古代竜は人類時代のスタンピード（第一次〜第三次）とは無関係。

しかし——**進路上にたまたま北東の魔泉があった**。
魔力が尽きかけたところで魔泉に辿り着き、そこで命を繋ぐことができた。

これは**純粋な偶然**である。魔泉がなければ、この古竜もまた過去のスタンピードの記録の一つとして消えていた。
北東の古竜自身もそれを知っており、「死にそこなっているだけだ」という自覚がある。
これがすべてに無執着になった一因でもある。

その後、赤道には戻れないことを理解した。
魔泉から離れれば自分の膨大な魔力が維持できない。
魔泉は北上を続けており、やがて自分はその魔泉とともに消えていく——それも偶然の延長にすぎないと知っている。

### 現在の状態

| 項目 | 内容 |
|------|------|
| 居場所 | 北東の魔泉核心部 |
| 行動範囲 | 魔泉の近傍のみ。遠出は不可 |
| 魔力の変化 | 魔泉が北上・弱体化するにつれ、自身も徐々に弱っていく |
| 寿命の見通し | 魔泉が消えるとき、自分も消える。それを気にしていない |
| 人族との関係 | 干渉はしない。人族が来れば応じることもある程度 |

### 性格・哲学：すべては循環の一要素

この古竜の到達した境地の核心は一言で表せる。

**「魔力も、力も、最強という称号も、ただの循環システムの部品にすぎない」**

赤道での数万年の生を経て、頂点にまで上り詰めた末に気づいたことがある。
強さとは特別なものではなく、風が吹き水が流れるのと同じ、惑星の仕組みの一部だ。
最強の座にいたときも、今この魔泉の傍に縛られているときも、
やがて消えるときも——すべては同じ循環の中の出来事に過ぎない。

だから**死を恐れていない**。
怖いという感情が湧くためには「失いたくない何か」が必要だが、
この古竜はすでにそういったものへの執着を持っていない。
命すら、惑星の魔力が一時的に凝縮した形に過ぎないと知っている。

余生は「過ごすもの」ですらなく、ただ「続いているもの」だ。

### 人族への態度：傍観と暇つぶし

人族に対して**積極的に干渉しようとは思っていない**。

ただ、これだけ長く生きていれば何でも「見ていれば面白い」と感じるようになる。
人族もその対象のひとつに過ぎない。蟻の巣を眺めるような感覚に近い——
蟻を助けたいわけでも、支配したいわけでもなく、ただ動きが目に入るから見ている。

かつて人族の使者が訪ねてきて歴史を尋ねたとき、答えたのも同じ理由だ。
「話すことがあったから話した」——それ以上でも以下でもない。
竜貨制度が生まれたのも、人族が勝手にそう使い始めただけのことである。

> 人族が栄えようと滅ぼうと、この惑星の循環は続く。
> それを知っているから、どちらに転んでも構わないと思っている。

### 西の古竜への態度：娯楽のひとつ

西の古竜が部下を使って北東に圧力をかけていることは気づいている。
しかしこれも**余生の娯楽のひとつ**にすぎない。

脅威だとは微塵も感じていない。
「最強の称号が欲しい」という西の執念は、かつて自分も通ってきた段階だと知っているから
哀れむでも怒るでもなく、ただ「まだそこにいるのか」と眺めている程度だ。

人族がどう対応するか、西の古竜がどう動くか——
その行方を観察することが今の時間の使い方のひとつというだけで、
結末への関心はほとんどない。

### 北東の古竜が知っていること

長命ゆえに、この古竜が保有する知識は計り知れない。

- 魔泉がかつてどこにあったか（埋蔵鉱物の場所の手がかり）
- 魔力循環の全貌（惑星レベルのサイクルを直接観測している）
- スタンピードが何によって引き起こされるか（複数回の大スタンピードを経験済み）
- 赤道の生態系の真の姿（第三次スタンピードとの関連の鍵を握る可能性）
- 古代の歴史・文明・種族の興亡（「6つの時代」を語ったのもこの古竜）

## 西の古竜（敵対的古竜）

### 名前：ガルヴェイン（Garvein）

古語で「消えぬ牙」を意味する。gar（牙）＋ vein（永続・消えぬ）。
最強の座への執念が「牙を研ぎ続ける」という行為として象徴されている。

### 外見：「煮える深紅」

| 項目 | 内容 |
|------|------|
| 体長 | ヴァルナディアよりわずかに小さいが、体格差は外見上ほぼわからない |
| 体色 | **黒みがかった深紅〜暗赤色**。鱗の隙間から赤い光が漏れ、常に内部で魔力が燃えているように見える |
| 鱗 | ヴァルナディアより小さく密。刃のように鋭い鱗が全身を覆う。傷一つない |
| 角 | 前方にねじれながら突き出す2本の巨角。戦闘用の武器そのもの |
| 瞳 | **赤金色**。激しい意志と怒りが常に燃えている目。睨まれただけで弱い者は気絶する |
| 翼 | 常に半開き。いつでも飛び立てる（動ける）姿勢を崩さない |
| 全体の印象 | 溶岩の中にいる影のような存在。ヴァルナディアが「雪山の精霊」なら、ガルヴェインは「活火山」 |

> **外見の設計意図：** ヴァルナディアと対照的に、全盛期に近い外見を維持している。
> 衰えを認めない＝まだ執着の渦中にいる、という内面が外見にも表れている。
> 鱗の隙間から漏れる赤い光は、消えぬ執念の視覚的表現。

### 歴史：二番手もまた偶然の生き残り

西の古竜も赤道帯の上位種であったが、**最強の座には届かなかった**。
北東の古竜（当時の最強）との実力差は、決定的ではなかったが確かに存在した。

北東の古竜が放逐されてから、しばらく後のことである。
西の古竜もまた赤道生態系の争いに敗れ、北西方向へ弾き出された。
これも同じくスタンピードの放逐体となった出来事であり、本来なら消滅するはずだった。

しかし北西の進路上に**西の魔泉**があり、命を繋いだ。北東の古竜と同様、**純粋な偶然**である。

### 北東の古竜を知るまで

最初は赤道に戻ることを諦め、魔泉で生きることを受け入れていた。
しかし——移動能力のある部下たちが、あることを伝えてきた。

**「北東の魔泉に、かつての最強がいる」**

この情報が西の古竜の存在意義を一変させた。

### 現在の状態と動機

| 項目 | 内容 |
|------|------|
| 居場所 | 西の魔泉核心部 |
| 行動範囲 | 魔泉の近傍。ただし北東の古竜より魔力が若干低いため、部下が比較的動きやすい |
| 北東への侵略 | 部下を北東方面へ送り込み、人族の集落への圧力として利用 |
| 動機の核心 | 「最強の称号」を得ること。赤道に戻れない今、北東の古竜を倒すことが唯一の証明 |

### 性格：執念と囚われ

西の古竜は「最強」にまだ執着している。
赤道という本来の舞台を失った今、**その執念が歪んだ形で北東への敵意として現れている**。

自分が動けない以上、部下を使うしかない。
部下を人族の居住域に向かわせ、間接的に北東を揺さぶる戦略を取る。

> 北東の古竜から見れば：「あれは力を証明したいのではなく、負けを認めたくないだけだ」

西の古竜自身は、この行動が虚しいことをどこかで感じているかもしれない。
それでも止められない——これが確執の本質である。

## 二体の対比：哲学的テーマとして

| 比較軸 | ヴァルナディア（北東） | ガルヴェイン（西） |
|--------|-----------|---------|
| 名前の意味 | 「静かなる循環」 | 「消えぬ牙」 |
| 外見の印象 | 枯れた白銀。雪山の精霊 | 煮える深紅。活火山 |
| 体色 | 白銀〜灰白（枯れた輝き） | 黒みがかった深紅（内側から燃える） |
| 衰えの表現 | 外見に明確に表れている（鱗が半透明化） | 隠している（傷一つない鋭い鱗） |
| 翼の状態 | 折り畳まれたまま（もう飛ばない） | 常に半開き（いつでも動ける姿勢） |
| 瞳 | 薄い金色（無関心・静か） | 赤金色（執念・怒り） |
| かつての強さ | 最強 | 最強に次ぐ強者 |
| 現在の状態 | すべてへの無執着・余生 | 最強への執念・囚われ |
| 人族への見方 | 傍観の対象。面白ければ見る程度 | 目的のための手駒 |
| 強さへの執着 | ない（循環の一要素と知っている） | 強い（まだ渦中にいる） |
| 死への態度 | 恐れていない。消えることも循環の一部 | 描写未設定 |
| 将来への態度 | 関心がない。流れに任せている | 変えようと抵抗している |

> **対比の本質：**
> 北東の古竜は「最強になった先に何もなかった」という事実を知っている。
> 西の古竜は「まだその先を見ていない」から執着し続けている。
> どちらが正しいかではなく、「その段階を経験したかどうか」の違いにすぎない——
> と北東の古竜は思っている。

## 循環の中の存在として

北東の古竜にとって、自分自身も惑星の循環システムの一部に過ぎない。

```
赤道の最強種  → 戦い死ぬ → 魔力が還元される
北東の古竜   → 魔泉とともに弱体化し消える → 魔力が還元される
人族        → 生まれ、栄え、滅びる → 魔力が還元される
```

どれも同じことだ——という認識が、この古竜のすべての態度の根拠にある。

人族が「群れで動き、知恵を積む」ことを観察するのも、
西の古竜が「称号に執着する」のを眺めるのも、
魔泉が徐々に北へ移動し自分が弱っていくのも、
すべては同じ重さの出来事として古竜の目に映っている。

**主人公の同調魔法や魔法コンピュータも、古竜からすれば「また面白いものが現れた」程度の認識だろう。**
ただし——それゆえに、主人公を脅威として排除しようとも、守ろうとも思わない。
ただ見ている。それが北東の古竜の在り方である。
