# 3国設定

> 正式名称・首都は2026年4月確定済み。詳細な政治・文化・キャラクターは今後拡張する。

---

## 前提：3国が激しく対立しない理由

各国の南側は魔物の強力な領域に面している。どの国も南からの魔物の脅威を抱えており、他国との全面戦争に国力を使う余裕がない。表向きは「対魔物同盟」として協調関係を維持しているが、その内実は利害の一致による消極的な共存である。

国同士の摩擦は存在するが、領土の大規模な奪い合いよりも**外交・情報戦**の形をとることが多い。

## コンコルディア盟邦（西方国家）

> 正式名称：**コンコルディア盟邦**（Concordia）　※2026年4月確定

### 基本情報

| 項目 | 内容 |
|------|------|
| 位置 | 大陸西部。西方魔泉山脈（ガルヴェイン山脈）と中央平野の間に位置。西側に敵対的古竜ガルヴェインの禁域を抱える |
| 主な構成種族 | 現代亜人族が中心。人間も一定数いる |
| 政体 | 未設定（複数の亜人氏族による合議制？　強力な族長による統治？） |
| 経済基盤 | 未設定 |
| 気候 | ガルヴェイン山脈の雨影でやや乾燥気味。山脈からの河川で水を確保 |

### 成立の経緯

西方国家の亜人族は2つの経緯で西に集まっている。

**① 元々の先住者**
西方の土地には古くから現代亜人族の部族が居住していた。中央帝国が東から拡大してくる以前から、亜人族はここで独自の社会を築いていた。

**② 中央から追われた流民**
中央帝国の拡張と差別制度の強化により、居場所を失った亜人族が西方に流れ込んだ。追われた者たちにとって西方は「同族がいる最後の土地」であり、先住の亜人族にとっては「流民の受け入れ先」となった。

この2つが混在しているため、西方国家の内部には「古くからいる者」と「後から来た者」の間の軋轢もある。

### 社会的特徴

- 亜人族が主体だが、亜人と人間の間に生まれた者・人間でも亜人社会に溶け込んだ者も多く、種族的な純血主義は薄い
- 西方魔泉山脈を越えてガルヴェインの部下（魔物）が侵攻してくる脅威に常に晒されているため、軍事力・戦闘技術が高い
- 中央帝国への警戒と反感が文化の根底に流れている
- 内部の差別：種族間ではなく、**魔力持ち vs 無魔人**の差別が存在する。また古参の部族と新参流民の間の格差も根深い

### 竜神殿との関係

西の古竜への対抗という観点から、北東の古竜（竜神殿）との関係は比較的良好。竜貨の流通にも積極的。

## ドミナトゥス帝国（中央帝国）

> 正式名称：**ドミナトゥス帝国**（Dominatus）　※2026年4月確定

### 基本情報

| 項目 | 内容 |
|------|------|
| 位置 | 大河流域の中央部。東は東方魔泉山脈（ヴァルナディア山脈）でルクスマーレ王国と接し、西はコンコルディア盟邦と接する |
| 主な構成種族 | 人間が中心。亜人族は下層市民として存在 |
| 政体 | 帝国（皇帝による中央集権的統治） |
| 経済基盤 | 大河を活かした農業・内陸交易の中継 |
| 気候 | 2つの山脈に挟まれた雨影地帯。降雨量は少なく、大河と支流に強く依存 |

### 成立の経緯

東の国（現在のルクスマーレ王国）から、新天地を求めて東方魔泉山脈を越えた冒険的な人々が中央平野に辿り着き、大河流域の豊かな農地を基盤に国家を形成した。東の国より環境はやや厳しいが、大河の恵みにより農業が発展した。「人類こそが文明の担い手」という思想を持ち、周囲の集落・部族を吸収・統合しながら版図を広げてきた。

その過程で亜人族との衝突が多く、「亜人は下に置くか追い出す」という方針が帝国の基本姿勢となった。これが西方国家への亜人流民を生んだ歴史的原因でもある。

### 社会的特徴

- 人間至上主義の傾向が強いが、国土が広いため地域差が大きい
- **差別が最も激しい地域**：帝都周辺・帝国の中心部。ここでは亜人は市民権が制限され、特定の職業にしか就けない。無魔人も厳しい差別を受ける
- **差別が比較的緩い地域**：南方の魔物脅威地帯に近い辺境。魔物と戦うために亜人の力が必要なため、現場では種族を問わず協力する文化がある
- 拡張主義の傾向はあるが、南の魔物・西方国家・東方王国との三方向の緊張があり、現状維持が続いている

### 竜神殿との関係

竜貨の最大の流通国であり、竜神殿に対して政治的影響力を持とうとしている。しかし神殿は中立を建前とするため、表立った支配はできない。水面下での駆け引きが続いている。

## ルクスマーレ王国（東方王国）

> 正式名称：**ルクスマーレ王国**（Luxmare）　※2026年4月確定
> 王都：**ルメリア**（Lumeria）
> 王宮：**ルクスマーレ王宮**

### 基本情報

| 項目 | 内容 |
|------|------|
| 位置 | 東方魔泉山脈（ヴァルナディア山脈）の東側〜東海岸。山脈が西の自然国境、東は海。人類居住域で最も安全な土地 |
| 主な構成種族 | 人間が中心だが、亜人族・無魔人も比較的平等に扱われる |
| 政体 | 王国（伝統的な君主制だが議会的な合議の仕組みも持つ） |
| 経済基盤 | 最も安全な国土を基盤とした安定的な農業。ほぼ自給自足 |
| 気候 | ヴァルナディア山脈の雨影だが、東の海からの海風・季節風で適度な降雨。温暖湿潤 |

### 成立の経緯

人類が最初に定住した土地がルクスマーレの起源である。魔力の薄い東方平野は魔物の脅威が少なく、短命種である人類が生存できる数少ない安全地帯であった。ここに集落が生まれ、やがて国家へと発展した。人類発祥の地にして、最も古い文明圏である。

しかし、大規模スタンピードにより王都を含む国土が崩壊寸前にまで追い込まれた歴史を持つ。復興に際しては、まず水回りの整備（灌漑・上水道・下水道）が優先された。これは幾度もスタンピードで町が崩壊してきた経験から培われた知恵である。防衛体制の強化と四大属性の発展のため、王都を囲む四方に四大公爵領が築かれ、そこを拠点にさらに外側へ開拓地を広げていった。この復興の経験が、現在の村落開拓制度の基盤となっている。

> 詳細は [[建国と復興の歴史]] を参照

中央帝国ほどの拡張主義をとらず、安全な国土の中で独自の文化を育んだ。保守的と評されるのは政治体制の変化を嫌う傾向があるためで、社会的には他国より開放的である。

### 社会的特徴

- **この世界における最も穏やかな「安全地帯」**。完全な理想郷ではないが、他国と比べると格段に生きやすい
- 種族差別・身分差別は存在するが、制度として弱く、個人の能力・実績で評価される文化がある
- 人類発祥の地として最も長い歴史を持ち、多様な人々を受け入れてきたため、異質なものへの受容性が高い
- 亜人族も職人・商人・水夫として市民権を持ち、社会に統合されている
- 無魔人も差別はあるが、他国ほど苛烈ではなく、特定職への就業制限が主な差異
- 中央帝国の拡張主義に対しては距離を置き、外交的に中立を保とうとしている

### 竜神殿との関係

竜神殿とは良好な関係を持つ。人類で最も古い国家として古竜との交流の歴史が長く、竜貨の安定的な入手経路を確保している。

### 物語上の役割

東方魔泉山脈の向こうに「人類発祥の安全な土地がある」という伝承は、中央帝国や西方国家にも残っている。差別や迫害から逃れた亜人・無魔人・政治犯などが、命がけで山脈を越えて「東を目指す」という構図が成立する。実際に辿り着ける者はごくわずかだが、東方王国は「まだ希望がある場所」という伝説的な位置づけを持つ。

## 3国の関係

### 西方国家 vs 中央帝国

同じ平野に位置し、山脈で隔てられていないため、直接的な関係がある。歴史的な恨みがあり緊張が高い。直接戦争はしないが互いに牽制。詳細は未設定。

### 東方王国の孤立

ルクスマーレ王国は東方魔泉山脈（ヴァルナディア山脈）によって中央・西方と隔てられている。山脈は魔力が高く魔物も強いため、日常的な往来は不可能。たまに命がけで山を越える者がいる程度であり、東の国と他の2国の間に定期的な交流・交易・外交関係はほぼ存在しない。

```
【ガルヴェイン山脈】── 平地（コンコルディア ←→ ドミナトゥス）──【ヴァルナディア山脈】── 平地（ルクスマーレ）
      ↑                    ↑ 山脈で隔てられていない              ↑ 山脈で隔てられている
  西の魔泉              直接的な関係あり（詳細未設定）          ほぼ孤立
```

> **物語上の注意：** 「中央帝国や西方国家から逃れてきた者たちが東を目指す」という構図は、山脈越えが命がけの冒険であることを踏まえたうえで、それでも差別や迫害から逃れるために危険を冒す者がいる、という形で成立する。
