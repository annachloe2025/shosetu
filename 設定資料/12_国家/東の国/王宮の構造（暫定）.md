### 補足
- 王妃は武闘大会の優勝者 or 功績枠で選出される

- 王妃になった女性は王室の男性と子をなす義務がある
- 第100代〜第107代、第108代の王妃は死亡（戦死等）。その子供は存命の者あり

## 20歳の王妃（S7の救助者）の詳細

| 項目 | 内容 |
|------|------|
| 年齢 | 20歳 |
| 立場 | 王妃（王妃会議メンバー） |
| S7での役割 | **王妃会議をサボっている最中に暗殺現場に遭遇し、主人公を救助する** |
| 性格 | 合理的。観察力が高い。他人を完全には信用しない |
| 基本スタンス | 中立寄り（排除派でも保護派でもない） |
| 価値観 | 「使えるものは使う」「無意味な破壊はしない」「制度は絶対ではないが、軽く壊していいものでもない」 |
| 戦闘力 | あり。単独行動・状況判断が早い。「勝つ」より「状況を制御する」タイプ |
| 主人公への認識 | ただの子供ではなく「異常な存在」と直感的に理解。興味対象 |
| 事件後 | 主人公を助けたが犯人を逃がした → 「タイミングが良すぎる」ことで疑われる |

### 疑われる構造
- 王妃会議を欠席している（本来いるべき場所にいない）
- 事件直前に主人公の近くにいる
- 最初に現場に到着する
- 結果的に犯人を逃がす
→ 状況証拠的に「共犯では？」と疑いの目が向く

## 王子の枠と派閥

### 概要
- 第100代以降の王妃から生まれた王子：**12名**（うち成人11名）
- 全員が聖女の血を持つ（王妃×王室男性の子のため）
- 貴族学院卒業後に「王室入り」か「戦場へ」を選択
- 戦場を選んだ者や戦死者を除くと、王室に残っている王子は **6〜8名** 程度（暫定）

### 派閥構成

| 派閥 | 人数（目安） | スタンス | 動機 |
|------|------------|---------|------|
| **排除派** | 3〜4名 | 主人公（聖女の血を持つ女子）を排除したい | 制度防衛。自分たちの存在意義の消失への恐怖と怒り |
| **保護派** | 2〜3名 | 主人公をかばう、または利用しようとする | 制度変革の可能性に賭ける。または母王妃への忠誠 |
| **傍観派** | 3〜4名 | 動きを見守る | 事態を見極めてから動く。状況次第でどちらにも転ぶ |

### 実行犯の王子

| 項目 | 内容 |
|------|------|
| 年齢 | 未設定 |
| 所属 | 排除派 |
| 性格 | 極めて合理的。感情を抑圧し「役割」を最優先する |
| 動機 | 制度防衛＋自分の人生（閉じ込められた意味）の否定への恐怖 |
| 戦闘スタイル | 気配遮断→接近→一撃。失敗したら即撤退 |
| 主人公への認識 | 子供ではなく「制度を破壊する要因」 |

### 黒幕（未設定）
- 実行犯とは別の上位人物
- 王室内で排除派を束ねている存在
- S7時点では姿を見せない

### 家事・生活基盤（宮中の運営要員）

魔法で大幅に省力化されているが、人の手が必要な部分は残る。
約250名分（王族＋全スタッフ）の食事・衣類・環境を維持する。

| 区分 | 人数（目安） | 備考 |
|------|------------|------|
| 調理人 | 8〜12名 | 火魔法で火力は容易だが、仕込み・味付け・盛り付けは人の技術。約250名分の食事を賄う |
| 配膳係 | 4〜6名 | 王族の居室・会議場・騎士詰所・各部署への運搬 |
| 洗濯・衣類管理 | 3〜5名 | 水魔法で洗濯自体は容易。王妃の儀礼衣装や高級品の管理・修繕が主務 |
| 清掃・修繕 | 3〜5名 | 土魔法で建物の補修、水魔法で浄化。王宮は広いため日常の巡回清掃に人手が要る |
| 庭園・馬房 | 3〜5名 | 庭園は有機魔法使いが管理。馬の世話・馬車の整備。飼料の管理 |
| 倉庫・物資管理 | 2〜3名 | 食材・消耗品・備品の在庫管理と発注。内務官の管轄 |
| **生活基盤合計** | **約25〜35名** | |

#### 魔法による省力化の詳細
- 水魔法：水汲み・洗濯・浄水・下水処理が不要（水魔法使いが数名いれば足りる）
- 土魔法：建物の修繕・壁の補修・道の整備を代替
- 火魔法：調理の火力・暖房・照明が簡略化
- 有機魔法：庭園の維持・薬草の栽培
- → 現実の同規模宮廷（数百人の使用人）と比べ、半分以下の人数で同等の機能を維持

王妃会議の決定を実務に落とし、王宮の内部管理から地方行政との接続までを担う文官たち。
人口1000万人の国家の中枢として、宮中の管理だけでなく対外的な行政機能も持つ。

| 財務官・会計 | 3〜5名 | 王宮の予算管理に加え、国庫との連携。徴税報告の受理 |

| 地方行政官 | 3〜5名 | 各領からの請願・報告の受付と審査。王妃会議への上申書を作成 |
| 四大公爵家の常駐連絡官 | 4名 | 各公爵家から1名ずつ派遣。公爵家と王宮のパイプ役。事実上の外交官 |
| 王室管理官 | 2〜3名 | 男性後宮の管理。王子の出入り・外部接触の記録。S7では重要な立場（※後述） |

#### S7に関わるポイント
- **内務官**：王妃会議の日程を把握 → 警備の配置に影響する情報を持つ
- **王室管理官**：王子の行動を管理する立場 → 暗殺犯の王子が自由に動けた理由に関わる可能性（黙認？ 買収？ 不注意？）
- **四大公爵家の常駐連絡官**：各公爵家の利害を代弁。暗殺の背景に公爵家の思惑がある場合、ここが情報の通り道になりうる

### 王宮騎士団

王宮の警備に特化した精鋭部隊。国軍全体とは別組織。
人口1000万人の国家の王宮を守る部隊として、少数精鋭で構成。

| 区分 | 人数（目安） | 備考 |
|------|------------|------|
| 騎士団長 | 1名 | 王宮警備の最高責任者。王妃会議に警備報告を行う |
| 常時配置（門・要所・廊下） | 20〜25名 | 24時間の交代制。王宮内外の巡回を含む |
| 交代要員・待機 | 40〜50名 | 3交代制の非番＋緊急待機 |
| 王妃の専属護衛 | 各2名（計10名） | 王妃の外出・移動時に同行。王妃が戦闘力を持つため補佐的な立場 |
| 主人公（王女）付き護衛 | 2〜3名 | 常時配置。S7では王妃会議中に手薄になる |
| 王室（後宮）警備 | 5〜8名 | 王子の出入りを監視する立場でもある。王室管理官と連携 |
| **騎士団合計** | **約80〜100名** | 少数精鋭。一人一人が高い戦闘力を持つ |

### S7における警備の隙
- 王妃会議の日は会議場の警護に人員が集中
- 主人公の護衛2〜3名のうち1名が会議場に回される
- 残り1〜2名を実行犯（王子）が突破する — これが暗殺未遂の条件

## 権力構造の概要

```
【表の権力】
  王妃会議（最高意思決定機関）
    ├── 王妃5名（合議制）
    ├── 筆頭格 = 事実上の女王（誰かは未設定）
    └── 四大公爵家が影響力を行使

【裏の権力（S7に関わる）】
  王室（男性後宮）
    ├── 王子約10名
    ├── 排除派が暗殺を企図
    └── 黒幕（上位の人物。未設定）

【先王の扱い（要検討）】
  ブループリントでは「先王＝裏の実権」とあるが、
  現在の王家設定では先王の立ち位置が未設定。
  → 黒幕を先王にするか、別の人物にするか要決定
```
