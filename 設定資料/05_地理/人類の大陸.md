# 人類の大陸

## 大陸の基本情報

- **形状**: 北アメリカ大陸に類似した形。東西に海があり、内陸に2つの山脈が南北に走る
- **政治**: 大陸内に複数の国家が存在
- **方角別の状況**:
  - 西：海 → 西方平野 → 西方魔泉山脈 → コンコルディア・ドミナトゥス領 → 東方魔泉山脈 → ルクスマーレ領 → 東の海
  - 南：魔物が強すぎて人類は行けない
  - 北東：友好的古竜の領域・基本的に立入禁止
- **大陸断面図（西→東）**:
  ```
  西の海 ─ 平地 ─ 【ガルヴェイン山脈】─ 平地(コンコルディア+ドミナトゥス) ─ 【ヴァルナディア山脈】─ 平地(ルクスマーレ) ─ 東の海
  ```

## 地形

### 東方魔泉山脈（ヴァルナディア山脈）
- 赤道から北東方向に走り、北東の魔泉（ヴァルナディアの領域）へと続く山脈
- 魔泉が赤道から北へ移動した跡として形成された。長期間の高濃度魔力で地中の岩石が変質・隆起した結果
- **ルクスマーレ王国とドミナトゥス帝国の自然国境**として機能
- 魔力残滓の影響で平地より魔力が高く、魔物も強い。自然の防壁
- 魔力が高く魔物も強いため、山脈を越えることは極めて危険。日常的な往来は不可能
- たまに命がけで山を越える者がいる程度で、東西の国家間に定期的な交流はない
- 鉱物資源が豊富（鉄鉱石・金銀銅・魔力結晶）。山脈の麓には鉱山町が点在するが、山脈深部への採掘は危険を伴う
- 過去に火山活動があった痕跡を持つ。火山由来の地質が鉱物資源の豊富さの一因
- **山脈から東西に河川が流れ出す**。西側の支流は大河に合流し、東側の支流はルクスマーレの平野を潤して東の海へ注ぐ

### 西方魔泉山脈（ガルヴェイン山脈）
- 赤道から北西方向に走り、西の魔泉（ガルヴェインの領域）へと続く山脈
- 東方魔泉山脈と同様、魔泉の通過跡として形成
- **コンコルディア盟邦のさらに西側**に位置
- 山脈の向こう側が西の魔泉＝ガルヴェインの禁域
- ガルヴェインの部下（魔物）がこの山脈を越えて侵攻してくるのがコンコルディアの最大の脅威
- 過去に火山活動があった痕跡を持つ
- **山脈から東西に河川が流れ出す**。東側の支流はコンコルディアの平地を潤し、大河に合流する。西側は西の海へ

### 大河
- 大陸を南北に縦断
- 自然な国境線。西方国家と中央帝国の間では水運が物流の主力
- **東西の山脈からの支流が多数合流**しており、水量が豊富
- 支流の合流が大河の水量を支える主要因

### 河川システム

2つの山脈を水源として、大陸全体に河川網が広がっている。

```
西の海 ← 【ガルヴェイン山脈】→ 支流 → 大河 ← 支流 ← 【ヴァルナディア山脈】→ 東の海
```

- 山脈の河川は**魔力を微量に含む水**を運ぶ（魔泉由来の地質を通過するため）
- 河川沿いの土壌は魔力がやや高く、農地として優良 → 川沿いに集落が発展しやすい
- 山脈からの侵食で運ばれた堆積物が下流に溜まり、**粘土・珪砂などの建材資源**が河川流域で豊富に採取できる

### 気候と降雨パターン

北半球の偏西風（西→東）の影響で、降雨量に地域差がある。

| 地域 | 降雨量 | 理由 |
|------|--------|------|
| 西の海沿岸（ガルヴェイン山脈の西） | 多い | 西の海からの湿った風が直接当たる |
| ガルヴェイン山脈の東側（コンコルディア） | やや少ない | 山脈の雨影。ただし山脈からの河川で水は確保 |
| 中央平野（ドミナトゥス） | 少なめ | 2つの山脈に挟まれた雨影地帯。大河と支流に強く依存 |
| ヴァルナディア山脈の西麓 | やや多い | 残った湿気が山脈にぶつかり上昇気流で降雨 |
| 東方平野（ルクスマーレ） | 適度 | 山脈の雨影だが、東の海からの海風・季節風で補われる |

→ **ドミナトゥス帝国が大河に依存する農業国**という構造の気候的根拠

### 中央平野
- 大河流域の農業地帯
- ドミナトゥス帝国の中核領土
- 最も人口が多い居住域
- 雨影地帯のため大河・支流への依存度が高い。大河から離れると半乾燥地帯になる

### 東方平野・東海岸
- ルクスマーレ王国の領土。東方魔泉山脈の東側に広がる
- 2つの魔泉の通過経路から外れており、魔力残滓が少ない＝**人類居住域で最も安全な土地**
- ヴァルナディア山脈からの河川が東の海へ注ぎ、平野を潤す
- 人類発祥の地。魔力が最も薄く、最も安全な居住域
- 東の海からの湿気で気候は温暖湿潤

### 建材資源の分布

火山由来の山脈＋河川の侵食により、建材資源が大陸各地で入手可能。

| 資源 | 産出地 | 用途 |
|------|--------|------|
| 粘土 | 大河流域・支流の氾濫原 | 焼成レンガ・陶器 |
| 珪砂 | 河床・河口付近（火山岩の石英が風化） | ガラス製造 |
| 石灰石 | 山脈周辺 | 石灰モルタル（建築の接合材） |
| 鉄鉱石 | 両山脈 | 金属加工・武具 |
| 魔力結晶 | 山脈の高魔力地帯 | 術式石・魔法道具 |

### 交通インフラ：そり道

この世界には**車輪が存在しない**（[[技術体系と車輪の不在]] 参照）。陸上輸送はすべて**そり**で行われる。

- 主要街道は土魔法使いが路面を平滑化・硬化させた「**そり道**」として整備
- 「**土守（つちもり）**」と呼ばれる専門職が各地のそり道・水路・建築・防壁を維持管理
- 大河・支流の**水運**も重要な輸送手段（特にドミナトゥス帝国では交易の主力）
- 東方魔泉山脈は魔力が高く魔物も強いため、山越えは極めて危険。日常的な往来は不可能

## 2つの魔泉

### 北東の魔泉（友好的古竜）
- 北方山脈の向こう側に位置
- **友好的な古竜が1体君臨**
- 人類に世界の歴史を教えてくれた存在
- 北東の古竜と西の古竜は互いに敵対している
- 精鋭の使者や特定の人物とのみ交流がある

### 西の魔泉（敵対的古竜）
- 大陸西端の禁域に位置
- **敵対的な古竜が1体君臨**
- 北東の古竜とは長年の因縁がある
- 人類とは基本的に交わらない・むしろ脅威
- コンコルディア盟邦は常にこの脅威と向き合っている

## 国家（仮）

### コンコルディア盟邦（西方国家）
- 位置：大陸西部。西方魔泉山脈（ガルヴェイン山脈）と中央平野の間
- 特徴：亜人族中心。ガルヴェインの脅威と常に向き合う・屈強な戦士が多い
- 課題：西方魔泉山脈を越えて侵攻してくる魔物・ガルヴェインの部下

### ドミナトゥス帝国（中央帝国）
- 位置：大河流域の中央部。東は東方魔泉山脈、西はコンコルディアと接する
- 特徴：大河を活かした農業国。人間至上主義
- 課題：南方の魔物の脅威

### ルクスマーレ王国（東方王国）
- 位置：東方魔泉山脈の東側〜東海岸。王都ルメリア
- 特徴：人類発祥の地・人類居住域で最も安全な土地
- 課題：南方からの魔物の脅威（ただし他国より軽微）
