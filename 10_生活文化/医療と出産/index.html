    医療と出産¶

    この世界の医療は回復魔法の自己限定という根本的な制約の中で発展している。魔力を持つ全住民は免疫力が高く、疫病の流行は少ないが、ポーションと薬草がすべての治療の基盤となる。唯一の例外は同調魔法の使い手による他者治癒だが、その能力者は極めて稀少である。

    医療体制¶

    基本原則¶

    • 回復魔法は「自分自身にしか使えない」 → 身体強化の一種
    • 自分の魔力で自分の治癒力を底上げする仕組み
    • 他者の体に干渉することは通常の魔法ではできない
    • 唯一の例外が同調魔法の使い手
    • 他者の魔力に同調し、相手の体内から回復を促すことが可能
    • ただし同調魔法が使える人間は極めて稀少
    • → 一般的な医療はポーションと薬草に頼る

    3つの医療手段¶

    手段 担い手 効果 入手性
    ポーション 錬薬師 回復促進・魔力回復・体力回復・解毒 品質により高額だが流通している
    薬草療法 薬草師・村の知恵者 症状の緩和・解熱・鎮痛・殺菌 比較的安価。農村でも入手可
    同調魔法（回復） 同調魔法の使い手（激レア） 他者の傷を直接治癒。最強の医療 一般人はまず恩恵を受けられない

    ポーションの種類¶

    種類 効果 用途
    回復ポーション 傷の治癒を促進。自然治癒の数倍速 怪我・手術後の回復
    体力回復ポーション 疲労の回復・体力の急速な回復 重労働後・長距離移動後
    魔力回復ポーション 消費した魔力の回復を促進 魔力切れ・連戦後
    解毒ポーション 毒の中和・排出の促進 毒持ちの魔物による被害
    鎮痛ポーション 痛みの軽減 出産・重傷時

    → ポーションの原材料は薬草。薬草の知識と採集がこの世界では非常に重要。

    薬草の重要性¶

    • ポーションの原材料であり、そのまま煎じても効果がある
    • 薬草の知識は村の生死を左右する重要な技能
    • 薬草師は魔石の有無に関係なく務められる → 無魔人でも就ける重要職
    • 薬草の自生地は魔物の出没地域と重なることが多い → 採集には危険が伴う
    • 栽培できる薬草と、野生でしか育たない薬草がある

    感知魔法による診断¶

    • 感知系魔法使いが体内の魔力の乱れを感じ取る → 病気の診断
    • 「どこが悪いか」はわかるが「なぜ悪いか」はわからない
    • 微生物の概念がないため、感染症の根本原因を理解できない
    • 「魔力の流れが滞っている」「穢れが溜まっている」と診断する
    • 骨折・内臓の損傷は比較的正確に把握できる

    病気と疫病¶

    疫病が流行しにくい理由¶

    • この世界の全住民は微量でも魔力を持っている
    • 魔力は免疫力を底上げする効果がある → 感染症に対する抵抗力が高い
    • 特に魔石持ちは魔力量が多いため、病気にかかりにくい
    • 無魔人も微量の魔力があるため、現実の中世ほど疫病が猛威を振るうことはない
    • → この世界に「大疫病で人口が半減」するような事態は起きていない

    それでも病気はある¶

    • 魔力による免疫は万能ではない。風邪・腹痛・発熱などの軽い病気は普通にかかる
    • 栄養不足や過労で魔力が低下すると、免疫力も下がる
    • 老齢で魔力が衰えると病気にかかりやすくなる

    毒への対処¶

    • 猛毒を持つ魔物は普通に存在する → 毒は現実的な脅威
    • 刺される・噛まれる・毒霧を吸うなど、魔物との戦闘で毒被害は日常的
    • 解毒ポーションの常備が討伐者の必須装備
    • 薬草師が毒の種類に応じた解毒薬を調合する
    • 毒の知識は戦闘系の教育で必ず教わる基礎項目

    怪我の治療¶

    怪我の程度 対処 回復期間
    切り傷・打撲 薬草の湿布＋自己回復魔法 数時間〜1日
    骨折 土魔法で添え木を固定＋回復ポーション 数日〜1週間
    深い刺傷・裂傷 回復ポーション＋自己回復魔法 1〜2週間
    毒による被害 解毒ポーション＋体力回復ポーション 毒の種類による
    内臓損傷 高級回復ポーション＋同調魔法（あれば） 数週間
    四肢の喪失 治療不可能（魔法でも再生は不可能） ─

    → 魔法があっても「失ったものは戻せない」のがこの世界の医療の限界。 → 自己回復魔法は魔石持ちのみ有効に使える。無魔人は微量すぎてほぼポーション頼り。

    出産¶

    魔石持ちの出産¶

    • 女性は出産前に副魔石に十分な魔力を蓄える必要がある（[[副魔石|女性専用の生殖器官]]が5系統遺伝情報と魔力を子の主魔石の「種」に転写する。[[属性の遺伝起源]]）
    • 副魔石の魔力が不足した状態での出産は母体に危険（子の主魔石形成に必要な情報密度が足りず、子が無魔人になるリスクが跳ね上がる）
    • このため魔石持ちの女性は出産間隔が長い（2〜3年以上）
    • 出産時は同調魔法使いが立ち会うのが理想だが、稀少すぎて一般人は望めない
    • 実際には産婆（助産師）＋水魔法使い＋薬草師のチームが対応
    • 水魔法使い：清潔な水の確保・止血の補助
    • 薬草師：鎮痛・止血の薬草の準備。鎮痛ポーションの投与
    • 産婆：出産の実技を担う

    無魔人の出産¶

    • 魔力蓄積の制約がないため、出産間隔が短い → 人口増加の主因
    • ただし医療支援が薄い（水魔法使いの立ち会いがないことも多い）
    • 産婆と薬草師に頼る。農村では経験豊富な老婆が産婆役
    • 出産時の死亡率は魔石持ちより高い

    生後の魔石の確認（貴族・魔石持ちの家系のみ）¶

    • 貴族や魔石持ちの家系では、子が生まれた直後に産婆・家族の中の感知系魔法使い・医師が感覚的に魔石の有無を確認する
    • 高位の魔力持ちには赤子が魔石を持っているかどうかが「気配（魔力反応の有無）」で分かるため、改まった検査というより自然な確認作業
    • ただし感知系で分かるのは魔石の有無だけであり、属性・魔力量・系統適性は分からない（それらは6歳の魔力検査と実地試験で初めて判明する）。回路構造を読み取って系統を鑑定することは原理的に不可能（[[魔力回路と適性継承]] 参照）
    • 魔石があれば家の後継ぎ候補として扱われ、家独自の訓練・教育が早期から始まる
    • 平民は全員検査を行わない：感知系魔法使いの人材が限られ、また平民で魔石持ちが生まれる確率は極めて低いため（1%未満）、全員検査する制度は現実的に成立しない
    • 公式な魔力検査は6歳の学園入学時に全員一斉に行う（「[[教育制度と娯楽]]」参照）
    • 隠れ持ちの問題：辺境などで6歳検査を受けずに無魔人として育つ魔石持ちも稀にいる

    死と葬送¶

    死の認識¶

    • 感知系魔法使いが「魔力の消失」を確認することで死亡が判定される
    • 魔石持ちの場合、死後に魔石が急速に魔力を失うことで死が明確にわかる

    葬送の方法¶

    方法 対象 説明
    火葬 最も一般的 火魔法で遺体を焼く。灰を壺に入れて埋葬
    土葬 一部の地域・宗教 土魔法で墓穴を掘り、遺体を埋める。墓石を土魔法で成形
    水葬 海沿いの地域 船に遺体を乗せて海に送り出す。ルクスマーレの一部で行われる

    魔石の扱い¶

    • 魔石持ちの遺体から魔石を取り出すかどうかは文化的に議論がある
    • 実用主義的な立場：魔石は貴重な資源。回収して術式石の原材料にすべき
    • 尊厳重視の立場：魔石は本人の一部。遺体とともに葬るべき
    • 国や地域によって方針が異なる：
    • ドミナトゥス帝国：平民の魔石は国が回収する制度がある（反感の種）
    • ルクスマーレ王国：遺族の意思を尊重（回収を強制しない）
    • コンコルディア盟邦：戦死者の魔石は仲間が引き継ぐ慣習（戦士文化）

    追悼の文化¶

    • 火葬の煙が「魔力を天に還す」象徴とされている
    • 定期的な墓参り・追悼祭が各国で行われる
    • 有名な戦士・魔法使いの墓は巡礼地になることもある
