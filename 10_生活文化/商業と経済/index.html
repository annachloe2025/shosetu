    商業と経済¶

    この世界の商業発展は「自由市場の拡大」ではなく「生存のための強制的協力」に基づいている。魔法の属性分業により一人で完結した生活が不可能であり、外敵の脅威が絶対的な協力の必要性を強制する。これらの圧力が国家の統一と商業網の発達を促進してきた。

    なぜこの世界で商業が発達するか¶

    ① 魔法の属性分業 ── 一人では生きられない¶

    • 魔石持ちは全人口の5〜8%しかいない
    • さらにその中で属性が分かれる（土・水・火・風・植物・強化・感知）
    • 一人の魔法使いにできることは限られている
    • 土魔法使いは建物を作れるが、水は引けない
    • 火魔法使いは鍛冶ができるが、作物は育てられない
    • 感知師は警戒はできるが、建築はできない
    • → 一つの集落に必要な属性が全て揃うことはまずない
    • → 隣の村の鍛冶師に頼む、街から建築師を呼ぶ、といった村を跨いだ協力が日常

    ② 外敵の脅威 ── 協力しなければ死ぬ¶

    • 野生動物はすべて魔物。集落の外は常に危険
    • 都市の大型魔道具（浄化・感知塔）の維持には魔力の集約が必要
    • 防衛には戦闘系魔法使いが必要
    • スタンピード後の復興には建築系魔法使いが必要
    • → 人間同士で争っている余裕がない。協力こそが生存戦略
    • この圧力が国家としてのまとまりを強くし、都市間の協力体制（＝商業網）を促進

    ③ 魔物狩猟経済 ── 「狩り」が文明の燃料¶

    • 魔物を討伐して魔石を得る → 加工して術式石にする → 文明の基盤になる
    • この「狩猟 → 加工 → 生活基盤」のサイクルは狩猟採集社会に近い構造
    • ただし敵が強すぎるため、個人の狩猟ではなく組織的な討伐と流通網が必要
    • 討伐 → 魔石回収 → 術式石加工 → 流通 → 消費、という産業チェーンが成立

    まとめ：商業発達の構造¶

    魔法の属性分業 ─→ 一人で生活が完結しない ─→ 分業・交換が必須
         ↓
外敵の脅威 ────→ 集団化・国家化 ─────→ 都市間の協力体制
         ↓
魔物狩猟経済 ──→ 魔石の流通が必要 ───→ 商業網の発達

    → この世界の商業は「儲けたいから」ではなく「生き残るために」発達した。

    貨幣¶

    竜貨（りゅうか）¶

    • 古竜（ヴァルナディア）の竜神殿が発行する魔力を帯びた貨幣
    • 偽造が極めて困難（古竜の魔力が込められているため）
    • 3国共通で流通する唯一の国際通貨
    • 高額取引に使われる

    一般通貨¶

    • 各国が独自に発行する金属貨幣（金貨・銀貨・銅貨）
    • 日常の取引はこちらが主流
    • 国ごとに通貨の信用度が異なる → 両替商が存在

    物々交換¶

    • 農村では今も物々交換が主流
    • 「麦3袋＝羊毛1巻」のような相場が地域ごとに存在
    • 特に無魔人の集落では貨幣経済が浸透しておらず、労働交換が一般的

    税と魔力供出¶

    「魔力」が税である¶

    • この世界では魔力そのものが税の一形態
    • 都市の大型魔道具の維持、街道の整備、公共インフラの運営にはすべて魔力が必要
    • 魔石持ちの住民は魔力を供出する義務がある（魔力納税）
    • 無魔人は魔力の代わりに労働力か貨幣で納税

    税の種類¶

    税の種類 対象 内容
    魔力供出 魔石持ち 大型魔道具・公共インフラへの魔力充填
    労役 無魔人 道路整備の補助・荷役・清掃など
    貨幣税 商人・富裕層 出店料・通行税・取引税
    兵役 全住民 スタンピード時の動員。魔石持ちは前衛、無魔人は後方支援

    → 「全員がなんらかの形で社会に貢献する」のがこの世界の当然。 外敵の脅威がある以上、「何もしない」は許されない。

    市場¶

    都市の常設市場¶

    • 大都市には常設の市場広場がある
    • 朝の鐘で開場、夕方の鐘で閉場
    • 市場の管理は都市の行政が担当。出店料を徴収

    扱われる商品¶

    カテゴリ 代表的な商品
    食料品 穀物・野菜・果物・肉（家畜＋弱い魔物）・乾燥食品
    衣料品 有機魔法布・魔物毛皮・手織りの布
    日用品 陶器（土魔法製）・木器（有機魔法製）・蝋燭・泡実の石鹸
    術式石 照明用・暖房用・冷却用・感知用（最も高価な部類）
    薬草・ポーション 軽度の回復薬・健康茶・虫よけ薬草
    金属製品 包丁・鍬・釘・鍋（鍛冶製品）
    嗜好品 酒・香辛料・香草・装飾品
    魔石・魔物素材 未加工魔石・魔物の皮・骨・牙（討伐品）

    定期市（農村）¶

    • 農村では週に1〜2回の定期市が開かれる
    • 近隣の村から商人が集まる
    • 農村では市場が唯一の情報交換の場でもある
    • 魔石持ちの出張サービス（修繕・鍛冶・治療）が定期市に合わせて回ってくることも

    職業と魔法の関係¶

    魔法系の職業¶

    魔石持ちにしかできない仕事は高収入で社会的地位も高い。 属性ごとに専門分化しており、これが商業の根幹を作っている。

    職業 使う魔法 役割
    土守（つちもり） 土魔法 建築・水路・防壁・そり道の維持管理。公務員的な立場
    水守（みずもり） 水魔法 給排水の管理。公共インフラの要
    建築師 土魔法（＋火魔法） 建物の建設・修理
    織布師 有機魔法（織物系） 布地・衣類の製造
    鍛冶師 火魔法 金属加工。武器・農具・日用品（火魔法使いの独占領域）
    陶工 土魔法（＋火魔法） 陶器の製造
    錬薬師 各種魔法＋薬草知識 ポーション・薬の製造
    感知師 感知魔法 偵察・探索・医療診断・鉱脈調査
    護衛 各種戦闘魔法 商隊・要人の護衛。討伐隊

    → 一つの村にこれが全員揃うことはない。 足りない職能は隣の村や街から呼ぶ → これが商業網の原型。

    無魔人の仕事¶

    無魔人は主魔石を持たないため属性魔法の直接発動は事実上できないが、体組織全体に弱いマーキング能力が残存している（[[魔力分子とマーキング]]）。 そのため、術式石の駆動補助（数人がかり）や、魔石持ちが起こした現象の延命・微調整などの補助運用は可能で、 日常の作業にこの残存マーキング能力を補助的に使っている。

    職業 内容
    農民 耕作・収穫は人力中心。道具のマーキング維持や術式石農具の駆動補助で貢献
    牧畜 家畜の管理・飼育。荷竜や走鳥の世話も含む
    漁師 網や罠で魚を取る。魔石持ちが馴染ませた釣り具のマーキングを延命させる補助は可能
    大工（補助） 魔法建築の補助作業（型枠作り・材料運搬・術式石の起動補助）
    運搬人 そりの荷物の積み下ろし・荷竜の御者
    料理人 術式石を使った調理。術式石の駆動は可能、細かな火加減は魔石持ちに頼むのが一般的
    商人 交渉・会計・流通管理は魔法の強さと無関係
    家事使用人 貴族の館の清掃・洗濯・料理の下準備

    → 注目すべきは「商人」が魔力の大小に関係なくできる仕事だということ。 交渉力と流通の知識があれば経済的に成功できる。 実際に裕福な無魔人商人は少なくない。

    術式石の経済¶

    「魔石 → 術式石」の産業チェーン¶

    魔物の討伐 → 魔石の回収 → 術式師が加工 → 術式石として流通 → 住民が使用
    • 術式石はこの世界で最も高価な量産品
    • 原材料は魔物の魔石（討伐で入手）＋術式師の加工技術
    • 用途が広い（照明・暖房・冷却・浄化・感知・その他）ため需要が常に高い
    • 高品質な術式石は貴族や軍が優先的に確保 → 庶民には中〜低品質のものが回る
    • 術式石の流通量がその都市の生活水準を決めると言っても過言ではない

    魔石の価格変動¶

    • スタンピード後は魔物が減少 → 魔石の供給が減る → 価格高騰
    • 平時は討伐が安定して行われ → 魔石の供給が安定 → 価格も安定
    • スタンピードの周期が経済の好不況を決める大きな要因

    商人ギルドと商隊¶

    商人ギルドの役割¶

    • 都市間の物流は商人ギルドが組織的に管理
    • ギルドの提供する機能：
    • 護衛の手配（討伐者ギルドと連携）
    • 荷竜の保有・貸出
    • 荷物の保険（魔物による損失の補償）
    • 価格情報の共有（都市間の相場差を把握）
    • 両替業務

    商隊¶

    • 商隊の定期便が都市間を結ぶ（現実世界のキャラバンに相当）
    • 一般人が都市間を移動するときも商隊に同行する
    • 商隊は「移動する市場」でもある → 通過する農村に商品を卸す

    ギルドの力の源泉¶

    • 荷竜の保有数がギルドの力の指標
    • 護衛を雇える資金力
    • 都市間の情報ネットワーク
    • → 大手ギルドは小さな国家に匹敵する影響力を持つことも

    各国の経済的特徴¶

    国 経済基盤 商業の特徴
    ドミナトゥス帝国 農業＋内陸交易 大河の水運で物流効率が最も高い。穀倉地帯を抱える
    ルクスマーレ王国 農業＋鉱物資源 最も安全な国土による安定した農業基盤。人類最古の文明圏として知識と技術が蓄積。ほぼ自給自足
    コンコルディア盟邦 軍事経済＋魔石産業 ガルヴェインの魔物討伐で魔石を大量入手。術式石の最大生産国

    西方と中央の経済関係： - コンコルディア盟邦とドミナトゥス帝国は同じ平野に位置し、山脈で隔てられていないため交易関係がある - 帝国は食料を、盟邦は術式石を、それぞれ供給し合う構造（詳細は未設定）

    東方王国の孤立： - ルクスマーレ王国は東方魔泉山脈によって他の2国と隔てられており、日常的な交易は存在しない - ほぼ完全な自給自足で国家が成立している。人類居住域で最も安全な土地であることが経済基盤の根本
