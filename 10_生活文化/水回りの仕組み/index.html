    水回りの仕組み¶

    集落の水回りは、川の流れ（重力）と水魔法の浄化を組み合わせた循環構造で成り立っている。機械やポンプは存在せず、高い場所から低い場所へ水が自然に流れる仕組みを基本とする。

    設計思想： 「川から借りた水は、きれいにして川に返す」 工業廃水のような深刻な汚染物質はこの世界には存在しないが、汚水をそのまま川に戻すことへの抵抗感が文化として根付いている。自然の恵みで生きている人々にとって、川を汚すことは「借りたものを汚して返す」ことと同じ感覚である。

    基本構造¶

    川上から支流を引き、浄化してから飲み水用のため池に溜める。生活排水は重力で下水用のため池に流れ落ちる。下水用ため池の水は浄化魔法をかけてから川下に戻す。

      ～～川上～～～～～～～～～～～～～～～～～～～～川下～～
        │                                    ↑
        │ 支流を引く                    浄化した水を返す
        ↓                                    │
    ┌──────────┐                      ┌──────────┐
    │            │                      │            │
    │  浄化魔法  │                      │  浄化魔法  │
    │            │                      │            │
    └─────┬──────┘                      └─────┬──────┘
          │                                    ↑
          ↓                                    │
    ┌──────────┐        生活排水         ┌──────────┐
    │  飲み水用  │   ─────使用後─────→   │  下水用    │
    │  ため池    │                        │  ため池    │
    │（高い位置）│                        │（低い位置）│
    └──────────┘                          └──────────┘
          │                                    │
          ↓ 重力で配水                         ↓
      住居・浴場・畑                       汚泥は肥料へ

    ポイント： - 川上と川下の2ヶ所に浄化用の術式石を設置する（入口と出口） - 術式石に魔力を流すだけで浄化が起動するため、水守でなくても使える - 飲み水用ため池は高い位置に置き、重力で集落内に配水する - 下水用ため池は低い位置に置き、生活排水が自然に流れ込む - 配水路・排水路は土魔法で地中に一体成型した暗渠（あんきょ） - 魔力を常時消費するのは浄化のときだけ。普段は重力で水が流れる

    水量の調整：土守による開閉¶

    支流の引き込み口には、恒久的なダムのような構造物は作らない。土守（土魔法使い）が必要に応じて土を盛って塞ぐ・土をどかして開けることで水量を調整する。

    • 大雨のとき： 土守が引き込み口に土壁を盛って支流を塞ぎ、水がため池に溢れるのを防ぐ
    • 雨が止んだら： 土壁を軟化させてどかし、再び支流を開く
    • 渇水のとき： 引き込み口を広げて多く取水する

    土魔法で壁の軟化→再硬化が自在にできるため、固定的なダムを築く必要がない。状況に応じてその場で地形を変えられるのが土魔法の強みであり、壊れる心配もメンテナンスも不要。

    風魔法使い（感知系）が天候の変化を察知して土守に知らせ、土守が水の引き込み口を調整するという連携が、村の水管理の基本となる。

    村の場合（小規模）¶

    構造¶

    • 川上から溝を掘って支流を引く（土魔法で成型）
    • 村の高台に飲み水用のため池を1つ。容量は村の1〜2日分
    • 村の低い場所に下水用のため池を1つ
    • 飲み水池から各戸への配水は、地中の暗渠か地表の水路
    • 下水用ため池から川下への排水路

    浄化の仕組み：術式石による運用¶

    ため池の浄化ポイントには、浄化魔法を転写した術式石が設置されている。魔力を流すだけで術式が起動するため、水魔法の適性がなくても使える。

    • 水守が運用する場合： 魔力が豊富なため1人で十分。日課として朝夕に術式石を起動する
    • 水守が不在の場合： 無魔人でも微量の魔力は持っているため、数人がかりで魔力を流せば術式石を起動可能。完全ではないが最低限の浄化を維持できる

    この仕組みのおかげで、水守が病気や戦闘で離脱しても村の水回りが即座に崩壊することはない。ただし無魔人だけでの運用は負担が大きく、長期間の代替にはならない。

    水守の日課¶

    1. 朝：飲み水用ため池の術式石を起動。前日に川から流れ込んだ水を浄化。不純物（汚泥）を分離
    2. 夕方：下水用ため池の術式石を起動。浄化した水を川下に流す。汚泥を取り出す
    3. 汚泥は村の畑に肥料として撒く

    王都の場合（大規模）¶

    構造¶

    基本は村と同じだが、規模が格段に大きい。

    • 山脈からの河川の上流で取水
    • 王都の高台に大型の貯水池を複数設置
    • 区画ごとに配水網を整備（土魔法で一体成型した地下暗渠）
    • 区画ごとに下水用ため池を設け、最終的に川下で合流して排水
    • 取水口と排水口の両方で浄化を行う

    管理体制¶

    • 水公爵家（アクエリオン家）が水回り全体を統括
    • 大型の術式石を取水口・各区画の下水池・最終排水口に設置
    • 区画ごとに担当者を配置し、術式石の起動と管理を行う
    • 貯水池・暗渠の構造物の維持管理は土魔法使いが担当
    • 術式石の定期メンテナンス（補強転写）は術式師が実施
    • 浄化→配水→排水→浄化→放流の循環を毎日回す

    スタンピード後の復興と水回り¶

    王都がスタンピードで崩壊した際、復興の最初の作業が水回りの再建であった。

    1. まず川上から支流を引き直す（土魔法で水路を成型）
    2. 浄化して飲み水用ため池を作る
    3. 人が集まれるようになったら、居住区と下水路の整備に着手

    この「まず水」という順序が、その後の村落開拓の手順として制度化された。

    詳細は [[建国と復興の歴史]] を参照

    「川を汚さない」という感覚¶

    この世界の人々は、自分たちが自然の中で魔物と隣り合わせに生きていることを日常的に意識している。川は飲み水であり、農業用水であり、下流の集落の命でもある。汚水をそのまま川に流すことは、下流の人々への害であると同時に、自然の恵みへの冒涜として忌避される。

    実際には工業廃水のような深刻な汚染物質がないため、浄化せずに流しても生態系に致命的な影響はない。しかし「借りたものはきれいにして返す」という感覚が、水守の仕事に対する敬意と結びついて文化として根付いている。
