    魔石の仕組み¶

    魔石とは¶

    生物が体内で魔力分子を結晶化・濃縮させた器官。大気中に遍在する魔力分子を取り込んで個体化し、魔法を運用する中枢として機能する。

    魔石には3つの本質的な機能がある。

    • マーキング装置：体内を循環する魔力分子に「個人マーキング」を刻み、自分用の魔力に変える（[[魔力分子とマーキング]]）
    • 魔力タンク：マーキング済みの魔力分子を貯蔵する器。魔法の発動にはこの貯蔵魔力を消費する
    • 魔力回路の媒体：生きている間は、魔力回路が遺伝子と魔石の両方に記録されている

    進化的起源： 魔石は古代5系統の生物が環境適応の過程で獲得した「原始魔石」が進化したもの。 詳細は [[属性の遺伝起源]] を参照。

    マーキング装置としての魔石¶

    主魔石の最重要機能は、取り込んだ天然魔力分子に個体固有のパターンを刻むことである。 血液が肺を通って酸素を得るのと同じように、体内を巡る魔力分子は主魔石を常時通過し、マーキングされていく。

    • マーキングを受けた魔力分子だけが術者の意志で動かせる「自分用の魔力」になる
    • 他者のマーキングが刻まれた分子には、自分のマーキングを重ね書きできない（物理的拒絶）
    • マーキングは数時間で自然消失し、天然魔力分子に戻る

    魔石の色・属性パターンは、マーキング時に属性遺伝子由来の付加情報を魔力分子に刻む結果でもある。これが「火属性のマーキング済み魔力は火現象と親和しやすい」理由になる。

    詳細は [[魔力分子とマーキング]] および [[属性の遺伝起源]] を参照。

    魔力回路と遺伝子の関係¶

    生きている間¶

    魔石の魔力回路は、生きている生物の遺伝子に組み込まれている。遺伝子が魔力回路の「設計図」を保持し、魔石がその設計図に基づいて回路を維持・実行する。生物が生きている限り、遺伝子と魔石は連動して回路を保つ。

    死後¶

    生物が死ぬと、遺伝子による回路の維持が停止し、魔石に刻まれていた魔力回路は消失する。残るのは魔力回路のない「素の魔石」、すなわち魔力タンクとしての器のみである。

    ただし、死後の魔石にも魔力そのものは残留している。この残留魔力と器としての構造が、術式石や魔力資源としての利用を可能にしている。

    後天的な回路の刻印¶

    死後の魔石であっても、同じ魔法を繰り返し流し込むことで、新たに魔力回路を刻むことができる。何度も同じパターンの魔力が流れることで魔石の内部に回路が形成され、以後は少量の魔力でその魔法を再現できるようになる。

    既存の回路がある魔石にも、繰り返しの転写によって新しい回路を上書き・追加することが可能。物理的な溝ではなくエネルギーパターンであるため、書き換えに原理的な障壁はない（ただし既存回路との干渉で品質が落ちることはある）。

    これが術式石の原理である（詳細は「[[術式の仕組み]]」を参照）。

    魔石の2つの構造：タンクと回路¶

    魔石は2つの機能を持つ。

    • タンク（器）：魔力を蓄積・貯蔵する容量。魔石の大きさ・品質に比例する
    • 回路：魔法のパターンが記録されたエネルギー経路。魔力が回路を流れると魔法が発動する

    回路は物理的な溝ではなく、魔石内部に形成されるエネルギーのパターンである。普段は目に見えないが、魔力を流すと淡く光って浮かび上がる。その構造は脳のニューロンネットワークに似ており、無数の経路が複雑に絡み合っている。熟練の術式師が光る回路を観察しても、個々の経路が何を意味するのかを解析することは不可能。回路全体が一つの魔法として機能しているということしかわからない。

    物理的な溝ではないため、回路の上書き・書き換えが可能。これが術式石の再利用や、生物が新しい魔法を習得できる理由でもある。

    この2つの構造が「充電」と「発動」の区別を生む。

    充電と発動の区別¶

    発動（魔法の使用）¶

    魔力を回路に流し込む操作。回路に沿って魔力が走ると、タンクに貯まっていた魔力を引き込みながら魔法が再現される。

    • 何も考えずに魔力を流すと回路に吸い込まれる。回路は魔力の「通り道」として最も抵抗が低い経路になっているため、魔力は自然に回路に流れ込む
    • だから発動は簡単。術式石に魔力を流せば、特別な技術がなくても魔法が起動する
    • 無魔人でも数人がかりで魔力を流せば術式石を発動できる理由はこれ

    充電（魔力の補給）¶

    魔力をタンクに注ぐ操作。回路を避けて、器全体にじわっと浸透させる。

    • 回路は魔力を吸い込む性質があるため、回路を避けて注ぐには精密な魔力操作技術が必要
    • ゆっくり、均一に、回路に触れないように器全体に染み込ませるイメージ
    • 充電の方が発動より技術的に難しい。これが術式石の運用における重要な制約

    誰が充電できるか¶

    充電者 可否 理由
    魔石持ち（操作に慣れた者） 可能 回路を避けて魔力を注ぐ技術がある
    術式師 最も効率的 魔石の構造を熟知している
    魔石持ち（技術の低い者） 困難 回路に魔力が吸い込まれてしまい、充電しようとして発動してしまう
    無魔人 不可能 魔力量が少ない上に精密な操作ができない。発動のみ

    日常の帰結： 村の術式石（水浄化・魔物忌避など）は、水守や術式の扱いに慣れた魔石持ちが定期的に充電する。無魔人は「使う（発動する）」ことはできるが「補充する（充電する）」ことはできない。

    人間の魔石の充電¶

    人間の主魔石・副魔石も同じ原理。日常の魔力回復（睡眠・食事）は、体の自律的な機能として魔力がタンクに戻る過程。外部から他者の魔石に充電することは、通常は魔石の防護フィールドに阻まれて不可能。

    例外：同調魔法使いは他者の魔石に魔力を送り込める。これは同調魔法使いの主魔石が古代群体系統を含む5系統の遺伝子を均衡して濃く発現する稀な構造（[[属性の遺伝起源]]・[[同調魔法]]）を持ち、他者のマーキング紋様と共鳴してその防護フィールドを突破できるためであり、「他者の魔石への充電」が可能な唯一の存在。

    魔石＝魔力タンク¶

    基本原理¶

    魔石は魔力の貯蔵庫である。魔法を使うたびに貯蔵魔力が消費され、減っていく。

    状態 説明
    満タン 最大魔力量まで蓄積。魔法を自由に使える
    消費中 魔法の使用や日常活動で徐々に減少
    残量低下 魔法の威力が落ちる。体に倦怠感が出る
    残量ゼロ 魔法が発動できなくなる。充填が必要
    ゼロ状態で酷使 魔石が破損する。不可逆的な損傷

    魔力の回復・充填¶

    • 自然回復：休息・睡眠・食事で回復する。一晩の睡眠でほぼ全回復が基本
    • 食事による回復：死んだ生物の魔力は摂取可能（食料・薬草・ポーションの基礎原理）
    • 魔石の直接摂取：魔物は他の魔石を食べることで魔力を急速に回復できる（後述）
    • 外部充電：術式石など死後の魔石には、魔石持ちが技術的に充電できる（上述）

    主魔石¶

    • 位置：心臓付近
    • 対象：男女共通、すべての生物
    • 役割：
    • マーキング装置（魔力分子に個人マーキングを刻む）
    • 生涯保持する魔力タンク
    • 魔力回路の基盤
    • 属性遺伝子の発現場（どの古代系統の遺伝子が優勢かで結晶構造が決まる）
    • 破壊された場合：主魔石による集中マーキング機能と魔力タンクを失う。ただし体組織全体の微弱な分散マーキング能力は残るため生命は維持できる（詳細は下記破壊後生存の項／[[人間の魔力量]]）

    破壊後の生存者と無魔人の起源： 主魔石を破壊されても死なないため、破壊された個体が子を残すことがあった。 主魔石形成は遺伝情報に従って起こるが、何らかの理由で形成が伝わらない子孫が出現し、 これが代を重ねて無魔人として定着した（[[人間の魔力量]]）。 無魔人は主魔石を持たないが、体組織全体で極めて弱いマーキング能力を残しているため、 微量ながら「自分用の魔力分子」を持つことができる（[[魔力分子とマーキング]]）。

    副魔石（女性のみ）¶

    • 位置：丹田付近
    • 対象：女性のみ（男性は持たない）
    • 形成開始：10歳前後から自然形成が始まる
    • 役割：
    • 生殖魔石として、古代5系統（地中・水棲・火山・空中・群体）の遺伝情報を濃縮保管し、出産時に子の主魔石の「種」へ情報転写する器官
    • 自身の追加の魔力タンク（男性より約2倍の魔力量の根拠）
    • 5系統のうちどの系統の情報が濃く保持されるかが、次世代の初期属性発現を左右する

    重要な補足： - 副魔石という器官そのものは子に引き継がれない。娘は母の副魔石を受け取るのではなく、10歳前後に自身の主魔石が保持する情報を元に自前の副魔石を新規に形成する - 子の主魔石の種に転写されるのは「5系統遺伝情報」であり、物体としての副魔石ではない - 男児の場合、副魔石は形成されない

    進化的起源： 副魔石は古代生物群が陸上交配を繰り返す中で、5系統の遺伝情報を次世代に安定して受け渡すために 女性個体に特化して発達した生殖器官。出産のたびに濃縮した5系統情報を子の主魔石の種へ転写する。 詳細は [[属性の遺伝起源]] 「副魔石と属性遺伝」を参照。

    出産サイクル¶

    1. 副魔石が十分に育ち、母自身の5系統遺伝情報が濃縮される（父から受精時に届いた精子の遺伝子も統合される）。また生涯にわたる魔力循環を通じて、母の主魔石に刻まれた魔力回路パターンの一部が副魔石にもバッファされる
    2. 妊娠・出産時に、副魔石に保持された5系統情報・バッファされた回路パターン写し・一部の魔力が、子の主魔石の「種」に転写される（副魔石自体は母体に残る。詳細は[[魔力回路と適性継承]]）
    3. 出産後は副魔石が弱くなり魔力が一時低下
    4. 数年かけて副魔石が再形成・増大
    5. 出産を重ねるごとに主魔石も鍛えられ魔力が安定して増大する

    男性に副魔石がない含意¶

    • 男性の属性発現は、母親の副魔石から5系統情報として転写されたものが自身の主魔石内部で発現する形で起こる
    • 男性から子への属性伝達は、精子が運ぶ5系統遺伝子が配偶者の副魔石に統合される経路で行われる
    • したがって父親の属性も孫世代以降に副魔石経由で反映されうるが、直接的な濃縮器官を持たないぶん母親経由よりは影響が薄い

    女性が魔力で優位な理由¶

    副魔石を持つため、魔力量（タンク容量）が男性の約2倍になる。 魔力量が多いと全系統の底上げになるため、特に肉体強化において男性を大きく上回る。

    経産婦は特に強い：出産を繰り返すごとに主魔石も成長するため、子を産んだ女性ほど魔力が安定して高くなる。

    魔石が破壊された場合¶

    破壊された魔石 結果
    主魔石 魔力をすべて失う。生存は可能
    副魔石 出産能力と余剰魔力を失う。戦闘力は残る

    副魔石を意図的に破壊する行為は、出産能力の剥奪でもあるため極めて重い禁忌・戦争犯罪として扱われる。

    魔力ゼロ状態での破損¶

    魔石の魔力が完全にゼロになった状態でさらに魔力を絞り出そうとすると、魔石に物理的なひびが入り始める。これを続けると魔石は破損し、二度と修復できない。戦場では魔力残量の管理が生死を分ける。

    死後の魔石の採取¶

    魔物や魔石持ちの人類が死ぬと、体内から魔石を採取できる。

    採取された魔石の状態¶

    • 魔力回路：消失している（遺伝子による維持が停止したため）
    • 残留魔力：ある程度残っている（タンクに貯まっていた分）
    • 物質的構造：保存されており、魔力を受け取る・保持する性質は残る
    • 属性（色）：保存されている。生前の属性に応じた色をしている

    魔石の色と属性¶

    魔石は生前の属性に応じた色を持ち、死後もこの色は変わらない。人間の髪色と同じ対応関係。 色の起源は古代生物の環境色遺伝子が属性遺伝子と連鎖しているため（[[属性の遺伝起源]]）。

    区分 魔石の色 古代系統 記録できる魔法
    火（属性） 赤 火山系統 火属性の魔法のみ
    水（属性） 青 水棲系統 水属性の魔法のみ
    土（属性） 黄 地中系統 土属性の魔法のみ
    風（属性） 緑 空中系統 風属性の魔法のみ
    2属性 混合色 2系統の共発現 両方の属性の魔法を記録可能
    同調魔法使い（※属性ではない） 透明〜白 5系統の均衡発現（特に群体系統） 他者魔力への干渉系（希少。便宜上この表に併記するが、属性区分ではなく稀な主魔石構造の能力）
    • 色が一致しない魔法はほぼ記録不可能。 魔石の結晶構造が属性遺伝子で規定され、対応する属性の魔力パターンにしか回路を形成しないため
    • 「ほぼ」不可能 であり、極めて稀に異属性の転写が成功する例もある。ただし効率が極端に悪く、実用性は低い
    • 2属性の魔石 は、古代2系統の遺伝子が共に優勢発現した個体から得られる。幼少期に本来と異なる属性の魔法を集中的に使い続けることで眠っていた第二系統が活性化する例もある。魔物でも複数属性を使う種は存在する

    採取魔石の用途¶

    用途 説明
    術式石の素材 新たに魔力回路を刻んで魔道具にする（術式の仕組みを参照）
    魔力資源 残留魔力をエネルギー源として利用
    魔物の餌 魔物が食べて魔力を回復する（後述）

    魔物が魔石持ちを襲う理由¶

    魔物と魔石の捕食関係¶

    魔物は魔石を食べることで魔力を急速に回復できる。魔石は高純度の魔力タンクであり、通常の食事（植物や他の生物の肉）よりもはるかに効率的な魔力補給源となる。

    このため、魔物は魔石持ちの生物を本能的に優先して襲う傾向がある。

    • 魔石持ちの人間は、魔物にとって「歩く魔力タンク」に等しい
    • 魔力量の高い者ほど魔物に狙われやすい（より大きなタンクを持っているため）
    • 女性は副魔石も含めて魔力量が多いため、男性より襲われるリスクが高い

    魔物同士の捕食¶

    魔物は人間だけでなく、他の魔物も襲って魔石を奪う。これが魔物の生態系における弱肉強食サイクルの原動力の一つである。強い魔物ほど多くの魔石を食べて更に強くなるという正のフィードバックが生まれる。

    鶏と卵の問題（起源）¶

    最初の魔石は「惑星の魔核エネルギーが生命誕生時に自然結晶化したもの」とする。世界の誕生神話と絡めることで説明が成立する。

    その後、古代5系統の環境特化生物が環境ごとに原始魔石を進化させ、陸上交配期に現代種の魔石へと統合された。これが現代の魔石が「4属性（地中・水棲・火山・空中の4系統に由来）を発現し、稀に5系統が均衡発現する主魔石構造（＝同調魔法）を生む」という進化史的根拠である（[[属性の遺伝起源]]）。

    戦闘における魔石の戦略的意義¶

    魔石を狙った戦闘が独自の戦術要素となる。

    • 相手の主魔石を破壊 → 戦闘不能化（殺さずに無力化できる）
    • 相手の副魔石を破壊 → 残酷な禁忌行為として国際的に禁止されている
    • 相手の魔力を消耗させて枯渇を狙う → 長期戦・消耗戦の基本戦略
    • 魔物との戦いでは倒した魔物の魔石を回収 → 資源・術式素材として価値がある
